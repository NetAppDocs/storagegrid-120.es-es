Descubre cómo ampliar tu sistema StorageGRID para aumentar la capacidad o las funcionalidades sin interrumpir las operaciones. Puedes añadir volúmenes de almacenamiento a los nodos de almacenamiento existentes, añadir nuevos nodos de grid a un sitio existente o añadir un nuevo sitio.

Antes de ampliar un nodo de la red, debes confirmar que no haya ningún trabajo de reparación de datos activo. Si alguna reparación ha fallado, debes reiniciarla y dejar que termine antes de realizar el procedimiento de decomisionar o ampliar. Consulta link:../maintain/checking-data-repair-jobs.html["Comprobar los trabajos de reparación de datos"].

Una ampliación de StorageGRID te permite añadir:

* ${post_edited_translations.segment}
* Nuevos nodos de grid en un sitio existente
* Un sitio completamente nuevo


El motivo por el que realizas la expansión determina cuántos nodos nuevos de cada tipo debes añadir y la ubicación de esos nuevos nodos. Por ejemplo, existen diferentes requisitos de nodos si realizas una expansión para aumentar la capacidad de almacenamiento, añadir capacidad de metadatos o añadir redundancia o nuevas funciones.
