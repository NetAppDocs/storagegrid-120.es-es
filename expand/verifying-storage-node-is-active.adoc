= Comprueba que los nodos de almacenamiento estén activos tras una ampliación de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Una vez completada la operación de expansión que añade nuevos nodos de almacenamiento, el sistema StorageGRID debería empezar a utilizar los nuevos nodos de almacenamiento de forma automática. Debes usar el sistema StorageGRID para verificar que el nuevo nodo de almacenamiento está activo.

.Pasos
. Inicia sesión en Grid Manager usando una link:../admin/web-browser-requirements.html["navegador web compatible"] cuenta.
. Selecciona *Nodos* > *_Nodo de almacenamiento de expansión_* > *Almacenamiento*.
. Coloca el cursor sobre el gráfico *Espacio utilizado - Datos de objetos* para ver el valor de *Utilizado*, que es la cantidad de espacio total utilizable que se ha usado para los datos de objetos.
. Comprueba que el valor de *Usado* vaya aumentando a medida que desplazas el cursor hacia la derecha en el gráfico.
