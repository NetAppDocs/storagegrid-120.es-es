= Cambios en la API de gestión de Grid en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.0 utiliza la versión 4 de la API de gestión de Grid. La versión 4 sustituye a la versión 3; sin embargo, las versiones 1, 2 y 3 siguen siendo compatibles.


NOTE: Puedes seguir utilizando las versiones obsoletas de la API de gestión con StorageGRID 12.0; sin embargo, el soporte para estas versiones de la API se eliminará en una futura versión de StorageGRID. Después de actualizar a StorageGRID 12.0, puedes desactivar las API obsoletas usando la API  `PUT /grid/config/management`.

Para obtener más información, visita link:../admin/using-grid-management-api.html["Usa la API de gestión de Grid"].



[[new-endpoints-for-branch-buckets]]
== Nuevos endpoints para los buckets de sucursales

Se han añadido los siguientes puntos finales para que puedas link:../tenant/what-is-branch-bucket.html["gestionar los buckets de las ramas"]:

`GET /org/containers/{branchBucketName}/branch`

`PUT /org/containers/{branchBucketName}/branch`



[[new-private-endpoints-for-move-adc]]
== Nuevos endpoints privados para Move ADC

Se han añadido los siguientes puntos finales privados para que puedas link:../maintain/move-adc-service.html["trasladar el servicio ADC"] de un nodo de almacenamiento a otro dentro del mismo sitio:

`/private/move-adc`

`/private/move-adc/start`

`/private/move-adc/retry`



[[new-private-endpoints-for-convert-to-data-only-node]]
== Nuevos puntos finales privados para convertir a nodo de solo datos

Se han añadido los siguientes puntos finales privados para que puedas link:../maintain/convert-to-data-only-node.html["convertir uno o varios nodos de almacenamiento combinados"] que no contengan el servicio ADC en nodos de solo datos.

`/private/convert-to-data-only-node`

`/private/convert-to-data-only-node/start`

`/private/convert-to-data-only-node/retry`
