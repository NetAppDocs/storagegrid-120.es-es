= Ver la pestaña Hardware de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La pestaña «Hardware» muestra la utilización de CPU y el uso de memoria de cada nodo, y también información adicional sobre el hardware de los appliances.


NOTE: El Grid Manager se actualiza con cada versión y es posible que no coincida con las capturas de pantalla de ejemplo que aparecen en esta página.

La pestaña «Hardware» se muestra para todos los nodos.

image:nodes_page_hardware_tab_graphs.png["Pestaña Hardware de la página Nodes"]

Para visualizar un intervalo de tiempo diferente, selecciona uno de los controles situados encima del gráfico. Puedes visualizar la información disponible para intervalos de 1 hora, 1 día, 1 semana o 1 mes. También puedes establecer un intervalo personalizado, lo que te permite especificar rangos de fecha y hora.

Para ver los detalles sobre la utilización de CPU y el uso de la memoria, coloca el cursor sobre cada gráfico.

image:nodes_page_memory_usage_details.png["Página de nodos > Hardware > Detalles del uso de la memoria"]

Si el nodo es un nodo de appliance, esta pestaña también incluye una sección con más información sobre el hardware del appliance.



[[view-information-about-appliance-storage-nodes]]
== Ver información sobre los nodos de almacenamiento de los appliances

La página «Nodos» muestra información sobre el estado del servicio y todos los recursos de computación, de disco y de red de cada Storage Node del appliance. También puedes ver la memoria, el hardware de almacenamiento, la versión del firmware del controlador, los recursos de red, las interfaces de red, las direcciones de red y los datos de recepción y transmisión.

.Pasos
. En la página Nodos, selecciona un Storage Node de appliance.
. Selecciona *Resumen*.
+
La sección «Información del nodo» de la pestaña «Resumen» muestra información resumida sobre el nodo, como el nombre del nodo, tipo, ID y estado de conexión. La lista de direcciones IP incluye el nombre de la interfaz para cada dirección, como sigue:

+
** *eth*: la red Grid, la red Admin o la red Client.
** *hic*: Uno de los puertos físicos de 10, 25 o 100 GbE del dispositivo. Estos puertos se pueden agrupar y conectar a la StorageGRID Grid Network (eth0) y Client Network (eth2).
** *mtc*: Uno de los puertos físicos de 1 GbE del dispositivo. Una o más interfaces mtc se agrupan para formar la interfaz de red de administración de StorageGRID (eth1). Puedes dejar otras interfaces mtc disponibles para que un técnico en el centro de datos tenga conectividad local temporal.
+
image:nodes_page_overview_tab_extended.png["Descripción general ampliada de la página Nodos"]

+
La sección de Alertas de la pestaña Resumen muestra cualquier alerta activa para el nodo.



. Selecciona *Hardware* para ver más información sobre el dispositivo.
+
.. Consulta los gráficos de utilización de CPU y de memoria para determinar los porcentajes de uso de CPU y memoria a lo largo del tiempo. Para mostrar un intervalo de tiempo diferente, selecciona uno de los controles situados encima del gráfico. Puedes visualizar la información disponible para intervalos de 1 hora, 1 día, 1 semana o 1 mes. También puedes establecer un intervalo personalizado, lo que te permite especificar rangos de fecha y hora.
+
image:nodes_page_hardware_tab_graphs.png["Gráficos de hardware"]

.. Desplázate hacia abajo para ver la tabla de componentes del dispositivo. Esta tabla contiene información como el nombre del modelo del dispositivo; los nombres de los controladores, los números de serie y las direcciones IP; y el estado de cada componente.
+

NOTE: Algunos campos, como «IP del controlador BMC de Compute» y «hardware de Compute», solo aparecen en los dispositivos que cuentan con esa función.

+
Los componentes de las estanterías de almacenamiento, y las estanterías de expansión si forman parte de la instalación, aparecen en una tabla independiente debajo de la tabla del appliance.

+
image:nodes_page_hardware_tab_for_appliance.png["Pestaña Hardware de la página Nodos para Appliance"]

== Ver información sobre los nodos de administración y los nodos de puerta de enlace del appliance

La página «Nodos» muestra información sobre el estado de los servicios y todos los recursos de computación, de disco y de red de cada dispositivo de servicios que se utiliza como Admin Node o Gateway Node. También puedes ver la memoria, el hardware de almacenamiento, los recursos de red, las interfaces de red, las direcciones de red y los datos recibidos y transmitidos.

.Pasos
. En la página Nodes, selecciona un appliance Admin Node o un appliance Gateway Node.
. Selecciona *Resumen*.
+
La sección «Información del nodo» de la pestaña «Resumen» muestra información resumida sobre el nodo, como el nombre del nodo, tipo, ID y estado de conexión. La lista de direcciones IP incluye el nombre de la interfaz para cada dirección, como sigue:

+
** *adllb* y *adlli*: Se muestran si se utiliza bonding activo/de respaldo para la interfaz de red de administración
** *eth*: la red Grid, la red Admin o la red Client.
** *hic*: Uno de los puertos físicos de 10, 25 o 100 GbE del dispositivo. Estos puertos se pueden agrupar y conectar a la StorageGRID Grid Network (eth0) y Client Network (eth2).
** *mtc*: Uno de los puertos físicos de 1 GbE del dispositivo. Una o varias interfaces mtc se agrupan para formar la interfaz de red de administración (eth1). Puedes dejar otras interfaces mtc disponibles para que un técnico del centro de datos disponga de conectividad local temporal.
+
image:nodes_page_overview_tab_services_appliance.png["Pestaña Descripción general de la página Nodos del dispositivo de servicios"]



+
La sección de Alertas de la pestaña Resumen muestra cualquier alerta activa para el nodo.

. Selecciona *Hardware* para ver más información sobre el dispositivo.
+
.. Consulta los gráficos de utilización de CPU y de memoria para determinar los porcentajes de uso de CPU y memoria a lo largo del tiempo. Para mostrar un intervalo de tiempo diferente, selecciona uno de los controles situados encima del gráfico. Puedes visualizar la información disponible para intervalos de 1 hora, 1 día, 1 semana o 1 mes. También puedes establecer un intervalo personalizado, lo que te permite especificar rangos de fecha y hora.
+
image:nodes_page_hardware_tab_graphs_services_appliance.png["Gráficos de la pestaña Hardware de la página Nodos del dispositivo de servicios"]

.. Desplázate hacia abajo para ver la tabla de componentes del appliance. Esta tabla contiene información como el nombre del modelo, el número de serie, la versión del firmware del controlador y el estado de cada componente.
