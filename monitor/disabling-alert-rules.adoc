= Desactiva las reglas de alerta en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes cambiar el estado de activación o desactivación de una regla de alerta predeterminada o personalizada.

.Antes de empezar
* Has iniciado sesión en Grid Manager mediante un link:../admin/web-browser-requirements.html["navegador web compatible"].
* Tienes el link:../admin/admin-group-permissions.html["Gestiona alertas o permisos de acceso root"].


.Acerca de esta tarea
Cuando se desactiva una regla de alerta, sus expresiones no se evalúan y no se activan alertas.


CAUTION: En general, no se recomienda desactivar una regla de alerta predeterminada. Si desactivas una regla de alerta, podrías no detectar un problema subyacente hasta que impida que se complete una operación crítica.

.Pasos
. Selecciona *Alertas* > *Reglas*.
+
Aparece la página Alert Rules.

. Selecciona el botón de opción correspondiente a la regla de alerta que quieras desactivar o activar.
. Selecciona *Editar regla*.
+
Aparece el cuadro de diálogo «Editar regla».

. Marca o desmarca la casilla *Habilitado* para determinar si esta regla de alerta está habilitada actualmente.
+
Si una regla de alerta está desactivada, sus expresiones no se evalúan y no se activan alertas.

+

NOTE: Si desactivas la regla de alerta de una alerta actual, debes esperar unos minutos para que la alerta deje de mostrarse como activa.

. Selecciona *Guardar*.
+
*Desactivado* aparece en la columna *Estado*.
