= Eliminar reglas de alerta personalizadas en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes eliminar una regla de alerta personalizada si ya no quieres utilizarla.

.Antes de empezar
* Has iniciado sesión en Grid Manager mediante un link:../admin/web-browser-requirements.html["navegador web compatible"].
* Tienes el link:../admin/admin-group-permissions.html["Gestiona alertas o permisos de acceso root"].


.Pasos
. Selecciona *Alertas* > *Reglas*.
+
Aparece la página Alert Rules.

. Selecciona el botón de opción correspondiente a la regla de alerta personalizada que quieras eliminar.
+
No puedes eliminar una regla de alerta predeterminada.

. Selecciona *Eliminar regla personalizada*.
+
Aparece un cuadro de diálogo de confirmación.

. Selecciona *OK* para eliminar la regla de alerta.
+
Cualquier instancia activa de la alerta se resolverá en un plazo de 10 minutos.
