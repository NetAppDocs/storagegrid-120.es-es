= Alertas en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Esta referencia enumera las alertas predeterminadas que aparecen en el Grid Manager. Las acciones recomendadas están en el mensaje de alerta que recibes.

Si lo necesitas, puedes crear reglas de alerta personalizadas que se adapten a tu enfoque de administración de sistemas.

Algunas de las alertas predeterminadas utilizan link:commonly-used-prometheus-metrics.html["Métricas de Prometheus"].
