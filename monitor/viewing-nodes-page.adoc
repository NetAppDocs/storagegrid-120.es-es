= Ver la página de nodos de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si necesitas información más detallada sobre tu sistema StorageGRID de la que ofrece el panel de control, puedes usar la página Nodos para ver las métricas de toda la grid, de cada sitio en la grid y de cada nodo en un sitio.

La tabla «Nodos» muestra información resumida sobre toda la grid, cada sitio y cada nodo. Si un nodo está desconectado o tiene una alerta activa, aparece un icono junto al nombre de nodo. Si el nodo está conectado y no tiene alertas activas, no se muestra ningún icono.


NOTE: Cuando un nodo no está conectado a la grid, como durante una actualización o en un estado desconectado, es posible que algunas métricas no estén disponibles o se excluyan de los totales del sitio y de la grid. Después de que un nodo se vuelva a conectar a la grid, espera varios minutos para que los valores se estabilicen.


NOTE: Para cambiar las unidades de los valores de almacenamiento que se muestran en el Grid Manager, selecciona el menú desplegable de usuario en la esquina superior derecha del Grid Manager y luego selecciona *User preferences*.


NOTE: Las capturas de pantalla que se muestran son ejemplos. Tus resultados pueden variar en función de tu versión de StorageGRID.

== Iconos de estado de conexión

Si un nodo se desconecta de la grid, aparecerá cualquiera de los siguientes iconos junto al nombre de nodo.

[cols="1a,3a,3a"]
|===
| Icono | Descripción | Acción requerida 


 a| 
image:icon_alarm_blue_unknown.png["icono de signo de interrogación azul"]
 a| 
*Sin conexión - Desconocido*

Por alguna razón desconocida, un nodo se ha desconectado o los servicios de dicho nodo han dejado de funcionar de forma inesperada. Por ejemplo, es posible que un servicio del nodo se haya detenido o que el nodo haya perdido la conexión a la red debido a un corte de corriente o a una interrupción inesperada.

También podría activarse la alerta *Unable to communicate with node*. Es posible que también haya otras alertas activas.
 a| 
Requiere atención inmediata. link:monitoring-system-health.html#view-current-and-resolved-alerts["Selecciona cada alerta"] y sigue las acciones recomendadas.

Por ejemplo, es posible que tengas que reiniciar un servicio que se haya detenido o reiniciar el host para el nodo.

*Nota*: Es posible que un nodo aparezca como «Desconocido» durante las operaciones de apagado controlado. En estos casos, puedes ignorar el estado «Desconocido».



 a| 
image:icon_alarm_gray_administratively_down.png["icono de signo de interrogación gris"]
 a| 
*Sin conexión - Fuera de servicio por motivos administrativos*

Por una razón previsible, el nodo no está conectado a la grid.

Por ejemplo, el nodo, o los servicios en el nodo, se ha apagado de forma controlada, el nodo se está reiniciando o el software se está actualizando. También puede haber una o más alertas activas.

Dependiendo del problema subyacente, estos nodos suelen volver a estar en línea sin intervención.
 a| 
Comprueba si hay alguna alerta que afecte a este nodo.

Si hay una o varias alertas activas, link:monitoring-system-health.html#view-current-and-resolved-alerts["Selecciona cada alerta"] y sigue las medidas recomendadas.

|===
Si un nodo se desconecta de la red, es posible que tenga una alerta subyacente, pero solo aparecerá el icono «No conectado». Para ver las alertas activas de un nodo, selecciona el nodo.



[[alert-icons]]
== Iconos de alerta

Si hay una alerta activa para un nodo, aparece uno de los siguientes iconos junto al nombre de nodo:

image:icon_alert_red_critical.png["Icono de alerta rojo crítico"] *Crítico*: Existe una condición anómala que ha detenido las operaciones normales de un nodo o servicio de StorageGRID. Debes solucionar el problema subyacente de inmediato. Si no resuelves el problema, podría haber interrupciones en el servicio y pérdida de datos.

image:icon_alert_orange_major.png["Icono de alerta naranja grave"] *Grave*: Existe una situación anómala que está afectando al funcionamiento actual o que se está acercando al umbral de una alerta crítica. Deberías investigar las alertas graves y resolver cualquier problema subyacente para asegurarte de que la situación anómala no detenga el funcionamiento normal de un nodo o servicio de StorageGRID.

image:icon_alert_yellow_minor.png["Icono de alerta amarillo menor"] *Menor*: El sistema funciona con normalidad, pero existe una situación anómala que, si continúa, podría afectar la capacidad del sistema para operar. Deberías supervisar y resolver las alertas menores que no se resuelvan por sí solas para asegurarte de que no resulten en un problema más grave.

== Ver detalles de un sistema, un sitio o un nodo

Para filtrar la información que se muestra en la tabla Nodos, introduce una cadena de búsqueda en el campo *Buscar*. Puedes buscar por nombre del sistema, nombre para mostrar o tipo (por ejemplo, introduce *gat* para localizar rápidamente todos los Gateway Nodes).

Para consultar la información sobre la grid, el sitio o el nodo:

* Selecciona el nombre de la grid para ver un resumen agregado de las estadísticas de todo tu sistema StorageGRID.
* Selecciona una ubicación concreta del centro de datos para ver un resumen global de las estadísticas de todos los nodos de esa ubicación.
* Selecciona un nodo concreto para ver la información detallada de ese nodo.
