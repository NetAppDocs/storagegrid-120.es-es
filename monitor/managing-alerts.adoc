= Administra alertas en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El sistema de alertas ofrece una interfaz fácil de usar para detectar, evaluar y resolver los problemas que pueden surgir durante el funcionamiento de StorageGRID.

Las alertas se activan en niveles de gravedad específicos cuando las condiciones de las reglas de alerta se evalúan como verdaderas. Cuando se activa una alerta, ocurren las siguientes acciones:

* En el panel de control de Grid Manager aparece un icono de gravedad de alerta y el recuento de Alertas actuales se incrementa.
* La alerta se muestra en la página de resumen *Nodos* y en la pestaña *Nodos* > *_node_* > *Overview*.
* Se envía una notificación por correo electrónico, siempre que hayas configurado un servidor SMTP y hayas indicado las direcciones de correo electrónico de los destinatarios.
* Se envía una notificación del Protocolo simple de gestión de redes (SNMP), siempre que hayas configurado el agente SNMP de StorageGRID.


Puedes crear alertas personalizadas, editar o desactivar alertas, y gestionar las notificaciones de alertas.
