* Si tienes previsto utilizar una interfaz VLAN en un grupo de alta disponibilidad (HA), ya has creado la interfaz VLAN. Consulta link:../admin/configure-vlan-interfaces.html["Configurar interfaces VLAN"].
* Si tienes previsto utilizar una interfaz de acceso para un nodo de un grupo de alta disponibilidad, ya creaste la interfaz:

** *Linux (antes de instalar el nodo)*: link:../swnodes/creating-node-configuration-files.html["Crear archivos de configuración de nodos"]

[[create-a-high-availability-group]]
== Crear un grupo de alta disponibilidad

Cuando creas un grupo de alta disponibilidad, seleccionas una o más interfaces y las organizas por orden de prioridad. Luego, asignas una o más direcciones VIP al grupo.

Una interfaz debe pertenecer a un Gateway Node o a un Admin Node para poder incluirse en un grupo de HA. Un grupo de HA solo puede usar una interfaz para un nodo determinado; sin embargo, puedes usar otras interfaces del mismo nodo en otros grupos de HA.

[[determine-the-priority-order]]
=== Determina el orden de prioridad

Si el grupo de HA incluye más de una interfaz, puedes determinar cuál es la interfaz primaria y cuáles son las interfaces de respaldo (conmutación por error). Si la interfaz primaria falla, las direcciones VIP se trasladan a la interfaz disponible que tenga la mayor prioridad. Si esa interfaz falla, las direcciones VIP se trasladan a la siguiente interfaz disponible con mayor prioridad, y así sucesivamente.

.Pasos
. ${post_edited_translations.segment}
+
La primera interfaz de la lista es la interfaz principal. La interfaz principal es la interfaz activa salvo que se produzca un fallo.

+
image:ha_group_determine_failover.png["Los grupos HA determinan el orden de prioridad"]

+

TIP: Si el grupo de HA proporciona acceso al Grid Manager, debes seleccionar una interfaz en el nodo de administración primario para que sea la interfaz primaria. Algunos procedimientos de mantenimiento solo se pueden realizar desde el nodo de administración primario.

. Selecciona *Continuar*.




[[enter-ip-addresses]]
=== Introduce direcciones IP

.Pasos
. En el campo *CIDR de la subred*, especifica la subred VIP en notación CIDR: una dirección IPv4 seguida de una barra y la longitud de la subred (0-32).
+
La dirección de red no debe tener ningún bit de host activado. Por ejemplo, `192.16.0.0/22`.

+

NOTE: Si utilizas un prefijo de 32 bits, la dirección de red VIP también sirve como dirección de puerta de enlace y dirección VIP.

+
image:ha_group_select_virtual_ips.png["Los grupos de HA introducen VIPs"]

. Si lo deseas, en caso de que algún cliente administrativo o de inquilino de S3 vaya a acceder a estas direcciones VIP desde una subred diferente, introduce la *dirección IP de la puerta de enlace*. La dirección de la puerta de enlace debe estar dentro de la subred VIP.
+
${post_edited_translations.segment}

. Introduce al menos una y no más de diez direcciones VIP para la interfaz activa del grupo de alta disponibilidad. Todas las direcciones VIP deben estar dentro de la subred VIP y todas estarán activas al mismo tiempo en la interfaz activa.
+
Debes proporcionar al menos una dirección IPv4. Si lo deseas, puedes especificar direcciones IPv4 e IPv6 adicionales.

. Selecciona *Crear grupo de alta disponibilidad* y selecciona *Finalizar*.
+
Se ha creado el grupo HA y ya puedes utilizar las direcciones IP virtuales configuradas.

[[remove-a-high-availability-group]]
== Eliminar un grupo de alta disponibilidad

${post_edited_translations.segment}


TIP: No puedes eliminar un grupo de alta disponibilidad si está vinculado a un punto final del equilibrador de carga. Para eliminar un grupo de alta disponibilidad, debes quitarlo de cualquier punto final del equilibrador de carga que lo use.

Para evitar interrupciones en los clientes, actualiza las aplicaciones cliente de S3 afectadas antes de eliminar un grupo de HA. Actualiza cada cliente para que se conecte usando otra dirección IP; por ejemplo, la dirección IP virtual de un grupo de HA diferente o la dirección IP configurada para una interfaz durante la instalación.

.Pasos
. ${post_edited_translations.segment}
. Revisa la columna *Puntos de conexión del equilibrador de carga* de cada grupo de alta disponibilidad que quieras eliminar. Si aparece algún punto de conexión del equilibrador de carga:
+
.. Ve a *Configuración* > *Red* > *Puntos finales del equilibrador de carga*.
.. Marca la casilla correspondiente al endpoint.
.. Selecciona *Actions* > *Edit endpoint binding mode*.
.. ${post_edited_translations.segment}
.. Selecciona *Guardar cambios*.


. ${post_edited_translations.segment}
. Selecciona *Acciones* > *Eliminar grupo de alta disponibilidad*.
. Revisa el mensaje y selecciona *Eliminar grupo de HA* para confirmar tu elección.
+
Se han eliminado todos los grupos de alta disponibilidad que has seleccionado. Aparece un banner verde de éxito en la página de grupos de alta disponibilidad.
