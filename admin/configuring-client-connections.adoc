= Configura conexiones de cliente S3 a StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Como administrador de grid, gestionas las opciones de configuración que controlan cómo las aplicaciones cliente de S3 se conectan a tu sistema StorageGRID para almacenar y recuperar datos.


TIP: Se han eliminado los detalles sobre Swift de esta versión del sitio de documentación. Consulta https://docs.netapp.com/us-en/storagegrid-118/admin/configuring-client-connections.html["StorageGRID 11.8: configura las conexiones de los clientes S3 y Swift"^].



[[configuration-tasks]]
== Tareas de configuración

. Realiza las tareas previas necesarias en StorageGRID, según cómo la aplicación cliente se conecte a StorageGRID.


[role="tabbed-block"]
====
.Tareas obligatorias
--
Debes obtener:

* Direcciones IP
* Nombres de dominio
* Certificado SSL


--
.Tareas opcionales
--
Opcionalmente, configura:

* Federación de identidades
* SSO


--
====
. Utiliza StorageGRID para obtener los valores que necesita la aplicación para conectarse a la grid. Puedes utilizar el asistente de configuración de S3 o configurar cada entidad de StorageGRID manualmente. +


[role="tabbed-block"]
====
.Usa el asistente de configuración de S3
--
Sigue los pasos del asistente de configuración de S3.

--
.Configurar manualmente
--
. Crear grupo de alta disponibilidad
. Crear un punto de conexión del equilibrador de carga
. Crear cuenta de inquilino
. Crear bucket y claves de acceso
. Configura la regla y la política de ILM


--
====
. Usa la aplicación S3 para completar la conexión con StorageGRID. Crea entradas de DNS para asociar direcciones IP a cualquier nombre de dominio que tengas pensado usar.
+
Si es necesario, realiza la configuración adicional de la aplicación.

. Realiza tareas periódicas en la aplicación y en StorageGRID para gestionar y supervisar el almacenamiento de objetos a lo largo del tiempo.

[[how-do-i-get-these-values]]
=== ¿Cómo obtengo estos valores?

En función de tus necesidades, puedes hacer cualquiera de las siguientes cosas para obtener la información que necesitas:

* *Usa el link:use-s3-setup-wizard.html["Asistente de configuración de S3"]*. El asistente de configuración de S3 te ayuda a configurar rápidamente los valores necesarios en StorageGRID y genera uno o dos archivos que puedes usar al configurar la aplicación S3. El asistente te guía a través de los pasos necesarios y te ayuda a asegurarte de que tu configuración cumpla con las mejores prácticas de StorageGRID.
+

NOTE: Si estás configurando una aplicación S3, se recomienda utilizar el asistente de configuración de S3, a menos que sepas que tienes requisitos especiales o que tu implementación vaya a requerir una personalización significativa.

* *Usa el link:../fabricpool/use-fabricpool-setup-wizard.html["Asistente de configuración de FabricPool"]*. De forma similar al asistente de configuración de S3, el asistente de configuración de FabricPool te ayuda a configurar rápidamente los valores necesarios y genera un archivo que puedes usar cuando configures un nivel de cloud de FabricPool en ONTAP.
+

NOTE: Si planeas usar StorageGRID como el sistema de almacenamiento de objetos para un nivel de cloud de FabricPool, se recomienda usar el asistente de configuración de FabricPool, a menos que sepas que tienes requisitos especiales o que tu implementación requerirá una personalización importante.

* *Configura los elementos manualmente*. Si te estás conectando a una aplicación S3 y prefieres no usar el asistente de configuración de S3, puedes obtener los valores necesarios realizando la configuración manualmente. Sigue estos pasos:
+
.. Configura el grupo de alta disponibilidad (HA) que quieras utilizar para la aplicación S3. Consulta link:configure-high-availability-group.html["Configurar grupos de alta disponibilidad"].
.. Crea el punto de conexión del equilibrador de carga que utilizará la aplicación S3. Consulta link:configuring-load-balancer-endpoints.html["Configura los puntos de conexión del equilibrador de carga"].
.. Crea la cuenta de inquilino que utilizará la aplicación S3. Consulta link:creating-tenant-account.html["Crear una cuenta de inquilino"].
.. Para un inquilino de S3, inicia sesión en la cuenta del inquilino y genera un ID de clave de acceso y una clave de acceso secreta para cada usuario que vaya a acceder a la aplicación. Consulta link:../tenant/creating-your-own-s3-access-keys.html["Crea tus propias claves de acceso"].
.. Crea uno o más buckets de S3 dentro de la cuenta de tenant. Para S3, consulta link:../tenant/creating-s3-bucket.html["Crear un bucket de S3"].
.. Para añadir instrucciones de ubicación específicas para los objetos que pertenecen al nuevo inquilino o bucket/contenedor, crea una nueva regla de ILM y activa una nueva política de ILM para usar esa regla. Consulta link:../ilm/access-create-ilm-rule-wizard.html["Crear regla de ILM"] y link:../ilm/creating-ilm-policy.html["Crear política de ILM"].
