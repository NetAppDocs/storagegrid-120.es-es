= Gestiona nodos de almacenamiento completos en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A medida que los nodos de almacenamiento alcanzan su capacidad, debes ampliar el sistema StorageGRID añadiendo nuevo almacenamiento. Hay tres opciones disponibles: añadir volúmenes de almacenamiento, añadir bandejas de expansión de almacenamiento y añadir nodos de almacenamiento.



[[add-storage-volumes]]
== Agregar volúmenes de almacenamiento

Cada nodo de almacenamiento admite un número máximo de volúmenes de almacenamiento. El máximo definido varía según la plataforma. Si un nodo de almacenamiento tiene menos volúmenes de almacenamiento que el número máximo, puedes añadir volúmenes para aumentar su capacidad. Consulta las instrucciones para link:../expand/index.html["Ampliar un sistema StorageGRID"].



[[add-storage-expansion-shelves]]
== Agrega bandejas de expansión de almacenamiento

Algunos nodos de almacenamiento de los dispositivos StorageGRID, como el SG6060 o el SG6160, pueden admitir bandejas de almacenamiento adicionales. Si tienes dispositivos StorageGRID con capacidad de expansión que aún no se han ampliado a la capacidad máxima, puedes añadir bandejas de almacenamiento para aumentar la capacidad. Consulta las instrucciones para link:../expand/index.html["Ampliar un sistema StorageGRID"].



[[add-storage-nodes]]
== ${post_edited_translations.segment}

Puedes aumentar la capacidad de almacenamiento añadiendo Storage Nodes. Al añadir almacenamiento, debes tener muy en cuenta las reglas de ILM actualmente activas y los requisitos de capacidad. Consulta las instrucciones para link:../expand/index.html["Ampliar un sistema StorageGRID"].
