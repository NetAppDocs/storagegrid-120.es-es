= Crear conexiones de federación de grid StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes crear una conexión de federación de grid entre dos sistemas StorageGRID si quieres clonar los detalles de los inquilinos y replicar los datos de los objetos.

Como se muestra en la figura, crear una conexión de federación de grid incluye pasos en ambos grids. Añades la conexión en un grid y la completas en el otro grid. Puedes empezar desde cualquiera de los grids.

image:grid-federation-create-connection.png["Resumen gráfico de los pasos para crear una conexión en dos grids"]

.Antes de empezar
* Has revisado link:grid-federation-overview.html["${post_edited_translations.segment}"] para configurar conexiones de federación de grid.
* ${post_edited_translations.segment}
* Estás usando un link:../admin/web-browser-requirements.html["navegador web compatible"].
* ${post_edited_translations.segment}




[[add-connection]]
== ${post_edited_translations.segment}

Sigue estos pasos en cualquiera de los dos sistemas StorageGRID.

.Pasos
. ${post_edited_translations.segment}
. Selecciona *Configuración* > *Sistema* > *Grid federation*.
. Selecciona *Add connection*.
. ${post_edited_translations.segment}

FQDN o dirección IP de esta grid
 a| 
Una de las siguientes opciones:

** El nombre de dominio completo (FQDN) de la grid en la que has iniciado sesión actualmente
** Una dirección VIP de un grupo HA en esta grid
** Una dirección IP de un nodo de administración o de un nodo de puerta de enlace en este grid. La dirección IP puede estar en cualquier red a la que pueda acceder el grid de destino.




 a| 
Puerto
 a| 
El puerto que deseas utilizar para esta conexión. Puedes introducir cualquier número de puerto no utilizado comprendido entre 23000 y 23999.

Ambas redes de esta conexión utilizarán el mismo puerto. Debes asegurarte de que ningún nodo de ninguna de las dos redes utilice este puerto para otras conexiones.



 a| 
Días de validez del certificado para este grid
 a| 
El número de días que quieres que los certificados de seguridad para este grid en la conexión sean válidos. El valor predeterminado es 730 días (2 años), pero puedes ingresar cualquier valor entre 1 y 762 días.

StorageGRID genera automáticamente certificados de cliente y de servidor para cada grid cuando guardas la conexión.



 a| 
Frase de contraseña de aprovisionamiento para este grid
 a| 
La frase de acceso de aprovisionamiento de la grid en la que has iniciado sesión.

. Selecciona *Guardar y continuar*.
. En el paso «Descargar el archivo de verificación», selecciona *Descargar el archivo de verificación*.
+
Después de que se complete la conexión en la otra grid, ya no podrás descargar el archivo de verificación de ninguna de las dos grids.

. Busca el archivo descargado (`_connection-name_.grid-federation` y guárdalo en una ubicación segura.
+

CAUTION: Este archivo contiene secretos (enmascarados como `***`) y otros detalles confidenciales, y debes almacenarlo y transmitirlo de forma segura.

. Selecciona *Cerrar* para volver a la página de Grid federation.
. Comprueba que aparezca la nueva conexión y que su *Estado de la conexión* sea *Esperando a conectarse*.
. Facilita el archivo  `_connection-name_.grid-federation` al administrador de grid de la otra grid.




[[complete-connection]]
== ${post_edited_translations.segment}

Sigue estos pasos en el sistema StorageGRID al que te vas a conectar (la otra grid).

.Pasos
. ${post_edited_translations.segment}
. Selecciona *Configuración* > *Sistema* > *Grid federation*.
. Selecciona *Subir archivo de verificación* para acceder a la página de subida.
. Selecciona *Subir archivo de verificación*. Luego, busca y selecciona el archivo que descargaste de la primera grid (`_connection-name_.grid-federation`).
+
Se muestran los detalles de la conexión.

. Opcionalmente, introduce un número diferente de días de validez para los certificados de seguridad de este grid. La entrada *Días de validez del certificado* toma de forma predeterminada el valor que introdujiste en el primer grid, pero cada grid puede usar diferentes fechas de caducidad.
+
En general, utiliza el mismo número de días para los certificados de ambos extremos de la conexión.

+

CAUTION: Si caducan los certificados de cualquiera de los extremos de la conexión, la conexión dejará de funcionar y las replicaciones quedarán pendientes hasta que se actualicen los certificados.

. ${post_edited_translations.segment}
. ${post_edited_translations.segment}
+
Se generan los certificados y se prueba la conexión. Si la conexión es válida, aparece un mensaje de éxito y la nueva conexión se muestra en la página de federación de Grid. El *Estado de la conexión* será *Conectado*.

+
Si aparece un mensaje de error, soluciona cualquier problema. Consulta link:grid-federation-troubleshoot.html["${post_edited_translations.segment}"].

. Ve a la página Grid federation en el primer grid y actualiza el navegador. Confirma que el *Estado de la conexión* ahora es *Conectado*.
. ${post_edited_translations.segment}
+
Si editas esta conexión, se creará un nuevo archivo de verificación. El archivo original no se podrá volver a utilizar.



.Después de que termines
* Consulta las consideraciones para link:grid-federation-manage-tenants.html["${post_edited_translations.segment}"].
* link:creating-tenant-account.html["Crear una o varias cuentas de inquilino nuevas"], asigna el permiso *Usar conexión de federación de grid* y selecciona la nueva conexión.
* link:grid-federation-manage-connection.html["Gestiona la conexión"] según sea necesario. Puedes editar los valores de conexión, comprobar una conexión, rotar los certificados de conexión o eliminar una conexión.
* link:../monitor/grid-federation-monitor-connections.html["Supervisa la conexión"] como parte de tus actividades habituales de supervisión de StorageGRID.
* link:grid-federation-troubleshoot.html["Soluciona los problemas de conexión"], incluida la resolución de cualquier alerta o error relacionado con la clonación de cuentas y la replicación entre grids.
