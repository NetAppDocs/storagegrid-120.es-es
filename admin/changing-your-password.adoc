= Cambia tu contraseña de StorageGRID Grid Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si eres un usuario local de Grid Manager, puedes cambiar tu propia contraseña.

.Antes de empezar
Has iniciado sesión en Grid Manager mediante un link:../admin/web-browser-requirements.html["navegador web compatible"].

.Acerca de esta tarea
Si te logueas en StorageGRID como usuario federado o si el inicio de sesión único (SSO) está habilitado, no puedes cambiar tu contraseña en Grid Manager. En su lugar, debes cambiar tu contraseña en la fuente de identidad externa, por ejemplo, Active Directory u OpenLDAP.

.Pasos
. En la barra de menú de Grid Manager, selecciona *_tu nombre_* > *Cambiar contraseña*.
. Introduce tu contraseña actual.
. Escribe una nueva contraseña.
+
Tu contraseña debe tener al menos 8 y no más de 32 caracteres. Las contraseñas distinguen entre mayúsculas y minúsculas.

. Vuelve a introducir la nueva contraseña.
. Selecciona *Guardar*.
