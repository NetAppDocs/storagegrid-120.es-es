= Permisos de gestión de tenants de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de crear un grupo de inquilinos, piensa qué permisos quieres asignar a ese grupo. Los permisos de gestión de inquilinos determinan qué tareas pueden realizar los usuarios mediante el Tenant Manager o la Tenant Management API. Un usuario puede pertenecer a uno o varios grupos. Los permisos se acumulan si un usuario pertenece a varios grupos.

Para iniciar sesión en Tenant Manager o usar la API de gestión de inquilinos, los usuarios deben pertenecer a un grupo que tenga al menos un permiso. Todos los usuarios que pueden iniciar sesión pueden realizar las siguientes tareas:

* Ver el panel de control
* Cambiar su propia contraseña (para usuarios locales)


En todos los permisos, la configuración del modo de acceso del grupo determina si los usuarios pueden cambiar la configuración y realizar operaciones o si solo pueden ver la configuración y las funciones relacionadas.


NOTE: Si un usuario pertenece a varios grupos y alguno de ellos está configurado como solo lectura, el usuario tendrá acceso de solo lectura a todos los ajustes y funciones seleccionados.

Puedes asignar los siguientes permisos a un grupo.

[cols="1a,3a,3a"]
|===
| Permiso | Descripción | Detalles 


 a| 
Acceso a raíz
 a| 
Ofrece acceso completo al Tenant Manager y a la Tenant Management API.
 a| 



 a| 
Gestiona tus propias credenciales de S3
 a| 
Permite a los usuarios crear y eliminar sus propias claves de acceso a S3.
 a| 
Los usuarios que no tengan este permiso no ven la opción de menú *ALMACENAMIENTO (S3)* > *Mis claves de acceso a S3*.



 a| 
Ver todos los buckets
 a| 
Permite a los usuarios ver todos los buckets y las configuraciones de los buckets.
 a| 
Los usuarios que no tengan ni el permiso «View all buckets» ni el permiso «Manage all buckets» no ven la opción de menú *Buckets*.

Este permiso queda reemplazado por el permiso Manage all buckets. No afecta a las políticas de grupo o de buckets de S3 que usan los clientes de S3 o la S3 Console.



 a| 
Gestionar todos los buckets
 a| 
Permite a los usuarios utilizar el Tenant Manager y la Tenant Management API para crear y eliminar buckets de S3 y gestionar la configuración de todos los buckets de S3 en la cuenta de inquilino, independientemente de las políticas de bucket de S3 o de grupo.
 a| 
Los usuarios que no tengan ni el permiso «View all buckets» ni el permiso «Manage all buckets» no ven la opción de menú *Buckets*.

Este permiso sustituye al permiso View all buckets. No afecta a las políticas de grupo o de buckets de S3 que usan los clientes de S3 o la S3 Console.



 a| 
Gestionar endpoints
 a| 
Permite a los usuarios utilizar Tenant Manager o la API de gestión de inquilinos para crear o editar puntos finales de servicios de la plataforma, que se utilizan como destino para los servicios de plataforma de StorageGRID.
 a| 
Los usuarios que no tengan este permiso no ven la opción de menú *Platform services endpoints*.



 a| 
Utiliza la pestaña S3 Console
 a| 
Cuando se combina con el permiso «Ver todos los buckets» o «Gestionar todos los buckets», permite a los usuarios ver y gestionar objetos desde la pestaña «Consola de S3» de la página de detalles de un bucket.
 a| 

|===
