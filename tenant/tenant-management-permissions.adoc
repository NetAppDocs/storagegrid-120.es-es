= Permisos de gestión de tenants de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de crear un grupo de inquilinos, piensa qué permisos quieres asignar a ese grupo. Los permisos de gestión de inquilinos determinan qué tareas pueden realizar los usuarios mediante el Tenant Manager o la Tenant Management API. Un usuario puede pertenecer a uno o varios grupos. Los permisos se acumulan si un usuario pertenece a varios grupos.

Para iniciar sesión en Tenant Manager o usar la API de gestión de inquilinos, los usuarios deben pertenecer a un grupo que tenga al menos un permiso. Todos los usuarios que pueden iniciar sesión pueden realizar las siguientes tareas:
