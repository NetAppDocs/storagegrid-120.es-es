= Conoce las notificaciones de eventos de StorageGRID para buckets S3
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes activar las notificaciones de eventos para un bucket de S3 si deseas que StorageGRID envíe notificaciones sobre eventos específicos a un clúster de Kafka, un endpoint de webhook o Amazon Simple Notification Service.

Por ejemplo, podrías configurar alertas para que se envíen a los administradores sobre cada objeto añadido a un bucket, donde los objetos representan archivos de registro asociados con un evento crítico del sistema.

Las notificaciones de eventos se crean en el bucket de origen tal como se especifica en la configuración de notificaciones y se entregan en el destino. Si un evento asociado a un objeto se realiza correctamente, se crea una notificación sobre ese evento y se pone en cola para su entrega.

No se garantiza la unicidad ni el orden de las notificaciones. Puede que se entregue más de una notificación de un evento al destino como resultado de las operaciones realizadas para garantizar el éxito de la entrega. Y como la entrega es asíncrona, no se garantiza que el orden de las notificaciones en el destino coincida con el orden de los eventos en el bucket de origen, especialmente para operaciones que se originan en diferentes sitios de StorageGRID. Puedes usar la clave  `sequencer` en el mensaje del evento para determinar el orden de los eventos de un objeto en particular, como se describe en la documentación de Amazon S3.

Las notificaciones de eventos de StorageGRID siguen la API de Amazon S3 con algunas limitaciones.

* Se admiten los siguientes tipos de eventos:
+
** s3:ObjectCreated:
** s3:ObjectCreated:Put
** s3:ObjectCreated:Post
** s3:ObjectCreated:Copy
** s3:ObjectCreated:CompleteMultipartUpload
** s3:ObjectRemoved:
** s3:ObjectRemoved:Delete
** s3:ObjectRemoved:DeleteMarkerCreated
** s3:ObjectRestore:post


* Las notificaciones de eventos enviadas desde StorageGRID utilizan el formato JSON estándar pero no incluyen algunas claves y utilizan valores específicos para otras, como se muestra en la tabla:
