= Actualizar la retención predeterminada de S3 Object Lock en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si activaste S3 Object Lock al crear el bucket, puedes editar el bucket para cambiar la configuración de retención predeterminada. Puedes activar (o desactivar) la retención predeterminada y establecer un modo de retención y un periodo de retención predeterminados.

.Antes de empezar
* Has iniciado sesión en el Tenant Manager con un link:../admin/web-browser-requirements.html["navegador web compatible"].
* Perteneces a un grupo de usuarios que tiene el link:tenant-management-permissions.html["Gestiona todos los buckets o permiso de acceso a raíz"]. Estos permisos anulan la configuración de permisos en las políticas de grupo o de bucket.
* S3 Object Lock está habilitado de forma global para tu sistema StorageGRID, y habilitaste S3 Object Lock al crear el bucket. Consulta link:using-s3-object-lock.html["Utiliza S3 Object Lock para conservar los objetos"].


.Pasos
. Selecciona *View buckets* desde el panel, o selecciona *STORAGE (S3)* > *Buckets*.
. ${post_edited_translations.segment}
+
Aparece la página de detalles del bucket.

. En la pestaña *Opciones del bucket*, selecciona el acordeón *S3 Object Lock*.
. Opcionalmente, activa o desactiva la *retención predeterminada* para este bucket.
+
Los cambios en esta configuración no se aplican a los objetos que ya están en el bucket ni a los objetos que puedan tener sus propios períodos de retención.

. Si la opción *Retención predeterminada* está activada, especifica un *modo de retención predeterminado* para el depósito.
+
[cols="1a,2a"]
|===
| Modo de retención predeterminado | Descripción 


 a| 
Gobernanza
 a| 
** Los usuarios con el permiso  `s3:BypassGovernanceRetention` pueden usar el encabezado de solicitud  `x-amz-bypass-governance-retention: true` para omitir la configuración de retención.
** ${post_edited_translations.segment}
** ${post_edited_translations.segment}




 a| 
Cumplimiento normativo
 a| 
** El objeto no se puede eliminar hasta que se alcance su fecha de retención.
** ${post_edited_translations.segment}
** La fecha de retención del objeto no se puede eliminar hasta que se alcance dicha fecha.


*Nota*: El administrador de tu grid debe autorizarte a utilizar el modo de cumplimiento.

|===
. ${post_edited_translations.segment}
+
El *período de retención predeterminado* indica durante cuánto tiempo deben conservarse los nuevos objetos añadidos a este bucket, a partir del momento en que se ingieren. Especifica un valor que sea menor o igual al período máximo de retención para el tenant, según lo haya establecido el administrador del grid.

+
El administrador de la grid establece un periodo de retención _máximo_, que puede ser un valor de 1 día hasta 100 años, al crear el tenant. Cuando estableces un periodo de retención _por defecto_, no puede superar el valor establecido para el periodo de retención máximo. Si lo necesitas, pídele a tu administrador de la grid que aumente o disminuya el periodo de retención máximo.

. Selecciona *Guardar cambios*.
