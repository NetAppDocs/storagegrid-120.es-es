= Mensaje de auditoría IDEL para eliminaciones iniciadas por ILM en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
${post_edited_translations.segment}

El mensaje IDEL se genera en cualquiera de estas situaciones:

* ${post_edited_translations.segment}
* *Para objetos en buckets de S3 no conformes*. Este mensaje se genera cuando ILM inicia el proceso de eliminación de un objeto porque actualmente no se aplica ninguna instrucción de ubicación de las políticas de ILM activas al objeto.

CMPA
 a| 
Cumplimiento: eliminación automática
 a| 
Solo para objetos en buckets S3 conformes. 0 (falso) o 1 (verdadero), que indica si un objeto conforme debe eliminarse automáticamente cuando termine su período de retención, a menos que el bucket esté bajo una retención legal.



 a| 
CMPL
 a| 
${post_edited_translations.segment}
 a| 
Solo para objetos en buckets de S3 conformes. 0 (falso) o 1 (verdadero), que indica si el bucket está actualmente bajo una retención legal.



 a| 
CMPR
 a| 
Cumplimiento normativo: plazo de conservación
 a| 
Solo para objetos en buckets S3 conformes. La duración del período de retención del objeto en minutos.



 a| 
CTME
 a| 
Cumplimiento: tiempo de ingesta
 a| 
Solo para objetos en buckets S3 compatibles. La hora de incorporación del objeto. Puedes sumar a este valor el periodo de retención en minutos para determinar cuándo se puede eliminar el objeto del bucket.
