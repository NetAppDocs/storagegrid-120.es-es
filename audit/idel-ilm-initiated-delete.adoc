= Mensaje de auditoría IDEL para eliminaciones iniciadas por ILM en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje se genera cuando ILM inicia el proceso de eliminación de un objeto.

El mensaje IDEL se genera en cualquiera de estas situaciones:

* *Para objetos en buckets S3 que cumplen los requisitos*: Este mensaje se genera cuando ILM inicia el proceso de eliminación automática de un objeto porque ha vencido su periodo de retención (suponiendo que la configuración de eliminación automática esté activada y la retención legal esté desactivada).
* *Para objetos en buckets de S3 no conformes*. Este mensaje se genera cuando ILM inicia el proceso de eliminación de un objeto porque actualmente no se aplica ninguna instrucción de ubicación de las políticas de ILM activas al objeto.


[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
CBID
 a| 
Identificador del bloque de contenido
 a| 
El CBID del objeto.



 a| 
CMPA
 a| 
Cumplimiento: eliminación automática
 a| 
Solo para objetos en buckets S3 conformes. 0 (falso) o 1 (verdadero), que indica si un objeto conforme debe eliminarse automáticamente cuando termine su período de retención, a menos que el bucket esté bajo una retención legal.



 a| 
CMPL
 a| 
Cumplimiento normativo: retención legal
 a| 
Solo para objetos en buckets de S3 conformes. 0 (falso) o 1 (verdadero), que indica si el bucket está actualmente bajo una retención legal.



 a| 
CMPR
 a| 
Cumplimiento normativo: plazo de conservación
 a| 
Solo para objetos en buckets S3 conformes. La duración del período de retención del objeto en minutos.



 a| 
CTME
 a| 
Cumplimiento: tiempo de ingesta
 a| 
Solo para objetos en buckets S3 compatibles. La hora de incorporación del objeto. Puedes sumar a este valor el periodo de retención en minutos para determinar cuándo se puede eliminar el objeto del bucket.



 a| 
DMRK
 a| 
Eliminar identificador de versión del marcador de eliminación
 a| 
El identificador de versión del marcador de eliminación creado al eliminar un objeto de un bucket con control de versiones. Las operaciones en los buckets no incluyen este campo.



 a| 
CSIZ
 a| 
Tamaño del contenido
 a| 
El tamaño del objeto en bytes.



 a| 
LOCS
 a| 
Ubicaciones
 a| 
La ubicación de almacenamiento de los datos del objeto dentro del sistema StorageGRID. El valor de LOCS es "" si el objeto no tiene ubicaciones (por ejemplo, si se ha eliminado).

CLEC: en el caso de los objetos con código de borrado, el identificador del perfil de código de borrado y el identificador del grupo de código de borrado que se aplican a los datos del objeto.

CLDI: para los objetos replicados, el ID del nodo LDR y el ID del volumen de la ubicación del objeto.

CLNL: ID del nodo ARC de la ubicación del objeto si los datos del objeto están archivados.



 a| 
RUTA
 a| 
Depósito/clave de S3
 a| 
El nombre del bucket de S3 y el nombre de la clave de S3.



 a| 
RSLT
 a| 
Resultado
 a| 
El resultado de la operación ILM.

SUCS: La operación de ILM se realizó correctamente.



 a| 
NORMA
 a| 
Etiqueta de reglas
 a| 
* Si un objeto de un depósito S3 conforme se está eliminando automáticamente porque ha vencido su periodo de retención, este campo está en blanco.
* Si el objeto se está eliminando porque ya no hay instrucciones de ubicación que se apliquen actualmente al objeto, este campo muestra la etiqueta legible para el usuario de la última regla de ILM que se aplicó al objeto.




 a| 
SGRP
 a| 
Sitio (Grupo)
 a| 
Si existía, el objeto se eliminó en el sitio especificado, que no es el sitio donde se ingirió el objeto.



 a| 
UUID
 a| 
Identificador único universal
 a| 
El identificador del objeto dentro del sistema StorageGRID.



 a| 
VSID
 a| 
ID de versión
 a| 
El ID de versión de la versión específica de un objeto que se eliminó. Las operaciones en buckets y objetos en buckets sin versiones no incluyen este campo.

|===
