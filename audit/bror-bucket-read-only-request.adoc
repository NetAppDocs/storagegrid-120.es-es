= Mensaje de auditoría BROR para solicitudes de solo lectura de bucket en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El servicio LDR genera este mensaje de auditoría cuando un bucket entra o sale del modo de solo lectura. Por ejemplo, un bucket entra en modo de solo lectura mientras se eliminan todos los objetos.

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
BKHD
 a| 
UUID del depósito
 a| 
El identificador del bucket.



 a| 
BROV
 a| 
Valor de la solicitud de solo lectura del bucket
 a| 
Si el bucket se está configurando como de solo lectura o si está dejando de estar en ese estado (1 = solo lectura, 0 = no solo lectura).



 a| 
BROS
 a| 
Motivo de solo lectura del bucket
 a| 
El motivo por el que el bucket pasa a ser de solo lectura o sale del estado de solo lectura. Por ejemplo, emptyBucket.



 a| 
S3AI
 a| 
ID de cuenta de inquilino de S3
 a| 
El ID de la cuenta de inquilino que envió la solicitud. Un valor vacío indica acceso anónimo.



 a| 
S3BK
 a| 
Bucket de S3
 a| 
El nombre del depósito de S3.

|===
