= Mensaje de auditoría EBKR para solicitudes de bucket vacíos en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje indica que un usuario envió una solicitud para activar o desactivar el bucket vacío (es decir, para eliminar los objetos del bucket o para dejar de eliminarlos).

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
BUID
 a| 
UUID del depósito
 a| 
El identificador del bucket.



 a| 
EBJS
 a| 
Configuración JSON de Empty Bucket
 a| 
Contiene el JSON que representa la configuración actual de Empty Bucket.



 a| 
S3AI
 a| 
ID de cuenta de inquilino de S3
 a| 
El ID de cuenta de inquilino del usuario que envió la solicitud. Un valor vacío indica acceso anónimo.



 a| 
S3BK
 a| 
Bucket de S3
 a| 
El nombre del depósito de S3.

|===
