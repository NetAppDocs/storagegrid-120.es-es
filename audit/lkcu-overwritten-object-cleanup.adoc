= Mensaje de auditoría LKCU para la limpieza de objetos sobrescritos en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje se genera cuando StorageGRID elimina un objeto sobrescrito que antes requería una limpieza para liberar espacio de almacenamiento. Un objeto se sobrescribe cuando un cliente S3 escribe un objeto en una ruta que ya contiene un objeto. El proceso de eliminación se realiza de forma automática y en segundo plano.
