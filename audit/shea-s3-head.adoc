= Mensaje de auditoría SHEA para operaciones S3 HEAD en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cuando un cliente S3 realiza una operación HEAD, se envía una solicitud para comprobar la existencia de un objeto o bucket y recuperar los metadatos de un objeto. Este mensaje lo envía el servidor si la operación se realiza con éxito.

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
CBID
 a| 
Identificador del bloque de contenido
 a| 
El identificador único del bloque de contenido solicitado. Si se desconoce el CBID, este campo se establece en 0. Las operaciones sobre los buckets no incluyen este campo.



 a| 
CNID
 a| 
Identificador de conexión
 a| 
${post_edited_translations.segment}



 a| 
${post_edited_translations.segment}
 a| 
Tamaño del contenido
 a| 
El tamaño del objeto verificado en bytes. Las operaciones sobre los buckets no incluyen este campo.



 a| 
${post_edited_translations.segment}
 a| 
${post_edited_translations.segment}
 a| 
Lista de los nombres y valores de los encabezados de las solicitudes HTTP registrados, según se seleccionaron durante la configuración.

 `X-Forwarded-For` se incluye automáticamente si está presente en la solicitud y si el valor de  `X-Forwarded-For` es diferente de la dirección IP del remitente de la solicitud (campo de auditoría SAIP).



 a| 
RSLT
 a| 
Código de resultado
 a| 
Resultado de la transacción GET. El resultado siempre es:

${post_edited_translations.segment}



 a| 
S3AI
 a| 
ID de la cuenta de inquilino de S3 (remitente de la solicitud)
 a| 
El ID de cuenta de inquilino del usuario que envió la solicitud. Un valor vacío indica acceso anónimo.



 a| 
S3AK
 a| 
${post_edited_translations.segment}
 a| 
El ID de la clave de acceso a S3 con hash del usuario que envió la solicitud. Un valor vacío indica acceso anónimo.



 a| 
S3BK
 a| 
${post_edited_translations.segment}
 a| 
El nombre del depósito de S3.



 a| 
S3KY
 a| 
Clave de S3
 a| 
El nombre de la clave S3, sin incluir el nombre del bucket. Las operaciones en buckets no incluyen este campo.



 a| 
SACC
 a| 
${post_edited_translations.segment}
 a| 
El nombre de la cuenta de inquilino del usuario que envió la solicitud. Vacío para solicitudes anónimas.



 a| 
SAIP
 a| 
Dirección IP (remitente de la solicitud)
 a| 
La dirección IP de la aplicación cliente que hizo la solicitud.



 a| 
${post_edited_translations.segment}
 a| 
Nombre de la cuenta de tenant de S3 (propietario del bucket)
 a| 
El nombre de la cuenta de inquilino del propietario del bucket. Se usa para identificar el acceso entre cuentas o el acceso anónimo.



 a| 
SBAI
 a| 
ID de la cuenta de tenant de S3 (propietario del bucket)
 a| 
El ID de la cuenta de inquilino del propietario del bucket de destino. Se utiliza para identificar el acceso entre cuentas o el acceso anónimo.



 a| 
SUSR
 a| 
URN de usuario de S3 (remitente de la solicitud)
 a| 
El ID de la cuenta del tenant y el nombre de usuario de la persona que realiza la solicitud. El usuario puede ser tanto un usuario local como un usuario LDAP. Por ejemplo: `urn:sgws:identity::03393893651506583485:root`

Dejar en blanco para solicitudes anónimas.



 a| 
HORA
 a| 
Tiempo
 a| 
${post_edited_translations.segment}



 a| 
TLIP
 a| 
Dirección IP de equilibrador de carga de confianza
 a| 
${post_edited_translations.segment}



 a| 
UUID
 a| 
Identificador único universal
 a| 
El identificador del objeto dentro del sistema StorageGRID.



 a| 
${post_edited_translations.segment}
 a| 
ID de versión
 a| 
El identificador de la versión específica de un objeto que se ha solicitado. Las operaciones en buckets y objetos de buckets sin versiones no incluyen este campo.

|===
