= Mensaje de auditoría GTED para tareas de grid finalizadas en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje de auditoría indica que el servicio CMN ha finalizado el procesamiento de la tarea de grid especificada y la ha trasladado a la tabla Historical. Si el resultado es SUCS, ABRT o ROLF, habrá un mensaje de auditoría correspondiente de Grid Task Started. Los demás resultados indican que el procesamiento de esta tarea de grid nunca se inició.

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
TSID
 a| 
ID de la tarea
 a| 
Este campo identifica de forma única una tarea de grid generada y permite gestionar dicha tarea a lo largo de su ciclo de vida.

*Nota:* el ID de tarea se asigna en el momento en que se genera una tarea de grid, no en el momento en que se envía. Es posible que una tarea de grid determinada se envíe varias veces y, en este caso, el campo ID de tarea no es suficiente para vincular de forma única los mensajes de auditoría Submitted, Started y Ended.



 a| 
RSLT
 a| 
Resultado
 a| 
Resultado final del estado de la tarea de la grid:

* SUCS: La tarea de la red se completó con éxito.
* ABRT: La tarea de la grid se terminó sin un error de reversión.
* ROLF: La tarea de grid se interrumpió y no pudo completar el proceso de reversión.
* CANC: El usuario canceló la tarea de la cuadrícula antes de que se iniciara.
* EXPR: La tarea de grid expiró antes de que se iniciara.
* IVLD: La tarea de la cuadrícula no es válida.
* AUTH: la tarea de la red no estaba autorizada.
* DUPL: La tarea de la cuadrícula fue rechazada por ser un duplicado.


|===
