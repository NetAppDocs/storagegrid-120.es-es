= Mensajes y registros de auditoría
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Estas instrucciones contienen información sobre la estructura y el contenido de los mensajes de auditoría y los registros de auditoría de StorageGRID. Puedes usar esta información para leer y analizar la pista de auditoría de la actividad del sistema.

Estas instrucciones son para los administradores responsables de generar informes sobre la actividad y el uso del sistema que requieran el análisis de los mensajes de auditoría del sistema StorageGRID.

Para utilizar el archivo de registro de texto, debes tener acceso al recurso compartido de auditoría configurado en el Admin Node.

Para obtener información sobre cómo configurar los niveles de los mensajes de auditoría y usar un servidor syslog externo, consulta link:../monitor/configure-log-management.html["Configura la gestión de registros y el servidor syslog externo"].
