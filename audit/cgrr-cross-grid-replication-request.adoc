= Mensaje de auditoría CGRR para solicitudes de replicación entre grids en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje se genera cuando StorageGRID intenta realizar una operación de replicación entre grids para replicar objetos entre buckets en una conexión de federación de grids.

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
CSIZ
 a| 
Tamaño del objeto
 a| 
El tamaño del objeto en bytes.

El atributo CSIZ se introdujo en StorageGRID 11.8. Como resultado, las solicitudes de replicación entre grids que abarquen una actualización de StorageGRID 11.7 a 11.8 podrían tener un tamaño total de objeto inexacto.



 a| 
S3AI
 a| 
ID de cuenta de inquilino de S3
 a| 
El ID de la cuenta de inquilino que es propietaria del bucket desde el que se está replicando el objeto.



 a| 
GFID
 a| 
ID de conexión de la federación de grid
 a| 
El identificador de la conexión de la federación de grid que se utiliza para la replicación entre grids.



 a| 
OPER
 a| 
Operación de CGR
 a| 
El tipo de operación de replicación entre grids que se intentó realizar:

* 0 = Replicar objeto
* 1 = Replicar objeto multiparte
* 2 = Replicar marcador de eliminación




 a| 
S3BK
 a| 
Bucket de S3
 a| 
El nombre del depósito de S3.



 a| 
S3KY
 a| 
Clave de S3
 a| 
El nombre de la clave S3, sin incluir el nombre del bucket.



 a| 
VSID
 a| 
ID de versión
 a| 
El identificador de la versión concreta de un objeto que se estaba replicando.



 a| 
RSLT
 a| 
Código de resultado
 a| 
Devuelve éxito (SUCS) o error general (GERR).

|===
