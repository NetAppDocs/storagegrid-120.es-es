= Mensaje de auditoría SVRF para fallos de verificación de almacén de objetos en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje se emite siempre que un bloque de contenido no supera el proceso de verificación. Cada vez que se leen o escriben en el disco datos de objetos replicados, se realizan varias comprobaciones de verificación e integridad para garantizar que los datos enviados al usuario que los solicita sean idénticos a los introducidos originalmente en el sistema. Si alguna de estas comprobaciones falla, el sistema pone automáticamente en cuarentena los datos de objetos replicados corruptos para evitar que se vuelvan a recuperar.

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
CBID
 a| 
Identificador del bloque de contenido
 a| 
El identificador único del bloque de contenido cuya verificación ha fallado.



 a| 
RSLT
 a| 
Código de resultado
 a| 
Tipo de error de verificación:

CRCF: Error en la comprobación de redundancia cíclica (CRC).

HMAC: Falló la comprobación del código de autenticación de mensajes basado en hash (HMAC).

EHSH: Hash de contenido cifrado inesperado.

PHSH: Hash de contenido original inesperado.

SEQC: Secuencia de datos incorrecta en el disco.

PERR: Estructura no válida del archivo en disco.

DERR: Error de disco.

FNAM: Nombre de archivo incorrecto.

|===

NOTE: Debes supervisar este mensaje de cerca. Los fallos de verificación de contenido pueden indicar fallos de hardware inminentes.

Para determinar qué operación activó el mensaje, consulta el valor del campo AMID (ID del módulo). Por ejemplo, un valor SVFY indica que el mensaje fue generado por el módulo Storage Verifier, es decir, verificación en segundo plano, y STOR indica que el mensaje fue activado por la recuperación de contenido.
