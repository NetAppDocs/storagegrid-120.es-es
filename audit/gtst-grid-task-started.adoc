= Mensaje de auditoría GTST para tareas grid iniciadas en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje de auditoría indica que el servicio CMN ha comenzado a procesar la tarea de grid especificada. El mensaje de auditoría sigue inmediatamente al mensaje Grid Task Submitted para las tareas de grid iniciadas por el servicio interno Grid Task Submission y seleccionadas para su activación automática. Para las tareas de grid enviadas a la tabla Pending, este mensaje se genera cuando inicias la tarea de grid.

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
TSID
 a| 
ID de la tarea
 a| 
Este campo identifica de forma única una tarea de grid generada y permite gestionar dicha tarea a lo largo de su ciclo de vida.

*Nota:* el ID de tarea se asigna en el momento en que se genera una tarea de grid, no en el momento en que se envía. Es posible que una tarea de grid determinada se envíe varias veces y, en este caso, el campo ID de tarea no es suficiente para vincular de forma única los mensajes de auditoría Submitted, Started y Ended.



 a| 
RSLT
 a| 
Resultado
 a| 
El resultado. Este campo solo tiene un valor:

* SUCS: La tarea de la grid se inició correctamente.


|===
