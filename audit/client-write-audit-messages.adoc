= Mensajes de auditoría para operaciones de escritura de clientes en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Los mensajes de auditoría de escritura del cliente se registran cuando una aplicación cliente de S3 realiza una solicitud para crear o modificar un objeto.

[cols="1a,3a,1a,1a"]
|===
| Código | Descripción | Utilizado por | Ver 


 a| 
OVWR
 a| 
Sobrescritura de objeto: registra una transacción para sobrescribir un objeto con otro objeto.
 a| 
Cliente S3
 a| 
link:ovwr-object-overwrite.html["OVWR: Sobrescritura de objeto"]



 a| 
SDEL
 a| 
S3 DELETE: Registra una transacción realizada con éxito para eliminar un objeto o un bucket.

*Nota:* Si la transacción se realiza sobre un subrecurso, el mensaje de auditoría incluirá el campo S3SR.
 a| 
Cliente S3
 a| 
link:sdel-s3-delete.html["SDEL: S3 DELETE"]



 a| 
SPOS
 a| 
S3 POST: Registra una transacción realizada con éxito para restaurar un objeto desde el almacenamiento de AWS Glacier a un Cloud Storage Pool.
 a| 
Cliente S3
 a| 
link:spos-s3-post.html["SPOS: S3 POST"]



 a| 
SPUT
 a| 
S3 PUT: Registra una transacción realizada con éxito para crear un nuevo objeto o bucket.

*Nota:* Si la transacción se realiza sobre un subrecurso, el mensaje de auditoría incluirá el campo S3SR.
 a| 
Cliente S3
 a| 
link:sput-s3-put.html["SPUT: S3 PUT"]



 a| 
SUPD
 a| 
Metadatos de S3 actualizados: registra una transacción exitosa para actualizar los metadatos de un objeto o bucket existente.
 a| 
Cliente S3
 a| 
link:supd-s3-metadata-updated.html["SUPD: Metadatos de S3 actualizados"]

|===
