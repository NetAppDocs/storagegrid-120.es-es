= Mensaje de auditoría LLST para ubicaciones de copias de objetos perdidas en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Este mensaje se genera cada vez que no se encuentra una ubicación para una copia de un objeto (replicada o con código de borrado).

[cols="1a,1a,4a"]
|===
| Código | Campo | Descripción 


 a| 
CBIL
 a| 
CBID
 a| 
El CBID afectado.



 a| 
ECPR
 a| 
Perfil de código de borrado
 a| 
Para datos de objetos con codificación de borrado. El ID del perfil de codificación de borrado utilizado.



 a| 
LTYP
 a| 
Tipo de ubicación
 a| 
CLDI (en línea): para datos de objetos replicados

CLEC (en línea): para datos de objetos con código de borrado

CLNL (Nearline): para datos de objetos replicados archivados



 a| 
NOID
 a| 
ID del nodo de origen
 a| 
El ID del nodo en el que se perdieron las ubicaciones.



 a| 
PCLD
 a| 
Ruta al objeto replicado
 a| 
La ruta completa a la ubicación en el disco de los datos del objeto perdido. Solo se devuelve cuando LTYP tiene el valor CLDI (es decir, para objetos replicados).

Adopta la forma `/var/local/rangedb/2/p/13/13/00oJs6X%{h{U)SeUFxE@`



 a| 
RSLT
 a| 
Resultado
 a| 
Siempre es NONE. RSLT es un campo de mensaje obligatorio, pero no es relevante para este mensaje. Se utiliza NONE en lugar de SUCS para que este mensaje no se filtre.



 a| 
TSRC
 a| 
Fuente desencadenante
 a| 
USUARIO: Activado por el usuario

SYST: activado por el sistema



 a| 
UUID
 a| 
Identificador único universal
 a| 
El identificador del objeto afectado en el sistema StorageGRID.

|===
