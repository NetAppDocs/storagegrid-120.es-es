= Descarga e instala paquetes RPM o DEB en todos los hosts Linux para StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si hay algún nodo de StorageGRID implementado en hosts Linux, descarga e instala un paquete RPM o DEB adicional en cada uno de estos hosts antes de iniciar la actualización.



[[download-upgrade-linux-and-hotfix-files]]
== Descarga archivos de actualización, Linux y corrección urgente

Cuando realizas una actualización de StorageGRID desde Grid Manager, el primer paso es descargar el archivo de actualización y cualquier corrección urgente necesaria. Sin embargo, si necesitas descargar archivos para actualizar hosts Linux, puedes ahorrar tiempo descargando todos los archivos necesarios con antelación.

.Pasos
. Ve a https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["Descargas de NetApp: StorageGRID"^].
. Selecciona el botón para descargar la última versión, o selecciona otra versión del menú desplegable y selecciona *Go*.
+
Las versiones del software StorageGRID tienen este formato: 11._x.y_. Las correcciones urgentes de StorageGRID tienen este formato: 11._x.y.z_.

. Inicia sesión con el nombre de usuario y la contraseña de tu cuenta de NetApp.
. Si aparece un aviso de precaución/MustRead, toma nota del número de la corrección urgente y selecciona la casilla de verificación.
. Lee el Acuerdo de licencia de usuario final (EULA), marca la casilla de verificación y luego selecciona *Aceptar & Continuar*.
+
Aparece la página de descargas de la versión que seleccionaste. La página contiene tres columnas.

. En la segunda columna (*Actualizar StorageGRID*), descarga dos archivos:
+
** El archivo de actualización para la última versión (este es el archivo en la sección etiquetada como *VMware, SG1000 o SG100 Primary Admin Node*). Aunque no necesitarás este archivo hasta que realices la actualización, descargarlo ahora te ahorrará tiempo.
** Un archivo RPM o DEB en formato `.tgz` o `.zip`. Selecciona el archivo `.zip` si estás ejecutando Windows en el portátil de servicio.
+
*** RHEL +
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.zip` +
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz`
*** Ubuntu o Debian +
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.zip` +
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.tgz`




. Si has tenido que aceptar un aviso de Caution/MustRead debido a la necesidad de instalar una corrección urgente, descarga la corrección urgente:
+
.. Vuelve a https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["Descargas de NetApp: StorageGRID"^].
.. Selecciona el número de corrección urgente en el menú desplegable.
.. Acepta de nuevo el aviso de advertencia y el EULA.
.. Descarga y guarda la corrección urgente y su README.
+
Cuando inicies la actualización, se te pedirá que subas el archivo de corrección urgente en la página de actualización de StorageGRID.



. La verificación de la firma de código es manual en un nodo Linux. Opcionalmente, verifica el archivo de instalación:
+
.. Descarga el paquete de verificación de la firma del código de StorageGRID. El nombre del archivo de este paquete usa el formato `StorageGRID_<version-number>_Code_Signature_Verification_Package.tar.gz`, donde `<version-number>` es la versión del software StorageGRID.
.. Sigue los pasos para link:../swnodes/download-files-verify.html["verificar manualmente los archivos de instalación"].






[[install-archive-on-all-linux-hosts]]
== Instala el archivo en todos los servidores Linux

Sigue estos pasos antes de actualizar el software de StorageGRID.

.Pasos
. Extrae los paquetes RPM o DEB del archivo de instalación.
. Instala los paquetes RPM o DEB en todos los hosts Linux.
+
Consulta los pasos para instalar los servicios de host de StorageGRID para Linux en link:../swnodes/installing-storagegrid-webscale-host-services.html["Instala los servicios de host de StorageGRID"].

+
Los nuevos paquetes se instalan como paquetes adicionales.





[[remove-installation-archives-for-previous-versions]]
== Eliminar los archivos de instalación de las versiones anteriores

Para liberar espacio en los hosts Linux, puedes eliminar los archivos de instalación de las versiones anteriores de StorageGRID que ya no necesites.

.Pasos
. Elimina los archivos de instalación antiguos de StorageGRID.

+
