= Revisa el estado de tu sistema StorageGRID antes de actualizar
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de actualizar un sistema StorageGRID, comprueba que el sistema esté preparado para la actualización. Asegúrate de que el sistema funcione con normalidad y de que todos los nodos de la red estén operativos.

.Pasos
. Inicia sesión en Grid Manager usando una link:../admin/web-browser-requirements.html["navegador web compatible"] cuenta.
. Comprueba si hay alertas activas y resuélvelas.
. Consulta link:../network/internal-grid-node-communications.html["Comunicaciones internas entre nodos de grid"] y link:../network/external-communications.html["Comunicaciones externas"] para asegurarte de que todos los puertos necesarios para StorageGRID 12.0 estén abiertos antes de realizar la actualización.
+

NOTE: No se necesitan puertos adicionales al actualizar a StorageGRID 12.0.
