= Verifica la versión instalada de StorageGRID antes de actualizar
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de iniciar la actualización, verifica que la versión anterior de StorageGRID esté instalada con la última corrección urgente disponible aplicada.

.Acerca de esta tarea
Antes de actualizar a StorageGRID 12.0, tu grid debe tener instalado StorageGRID 11.9.0.8 o una versión posterior. Si actualmente estás usando una versión anterior de StorageGRID, debes instalar todos los archivos de actualización anteriores junto con sus últimas correcciones urgentes (muy recomendable) hasta que la versión actual de tu grid sea al menos StorageGRID 11.9.0.8.

En la <<example-upgrade-path,ejemplo>> se muestra una posible ruta de actualización.


CAUTION: NetApp te recomienda encarecidamente que apliques la última corrección urgente para cada versión de StorageGRID antes de actualizar a la siguiente versión, y que también apliques la última corrección urgente para cada nueva versión que instales. En algunos casos, debes aplicar una corrección urgente para evitar el riesgo de pérdida de datos. Consulta https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["Descargas de NetApp: StorageGRID"^] y las notas de la versión de cada corrección urgente para obtener más información.
