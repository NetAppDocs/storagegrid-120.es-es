= Conoce la pérdida y la ausencia de datos de objetos en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Los objetos pueden recuperarse por varios motivos, como las solicitudes de lectura de una aplicación cliente, las verificaciones en segundo plano de los datos de objetos replicados, las reevaluaciones de ILM y la restauración de los datos de objetos durante la recuperación de un Storage Node.

El sistema StorageGRID utiliza la información de ubicación en los metadatos de un objeto para determinar de qué ubicación recuperar el objeto. Si no se encuentra una copia del objeto en la ubicación esperada, el sistema intenta recuperar otra copia del objeto de otro lugar del sistema, asumiendo que la política de ILM contiene una regla para realizar dos o más copias del objeto.

Si esta recuperación se realiza con éxito, el sistema StorageGRID sustituye la copia perdida del objeto. De lo contrario, se activa la alerta *Objetos potencialmente perdidos* de la siguiente manera:

* En el caso de las copias replicadas, si no se puede recuperar otra copia, el objeto se considera perdido y se activa la alerta.
* En el caso de las copias con codificación de borrado, si no se puede recuperar una copia de la ubicación esperada, el atributo Corrupt Copies Detected (ECOR) se incrementa en uno antes de intentar recuperar una copia de otra ubicación. Si no se encuentra ninguna otra copia, se activa la alerta.


Debes investigar inmediatamente todas las alertas de *Objetos potencialmente perdidos* para determinar la causa principal de la pérdida y comprobar si el objeto podría seguir existiendo en algún nodo de almacenamiento fuera de línea o que, por cualquier otro motivo, no esté disponible en ese momento. Consulta link:../troubleshoot/investigating-potentially-lost-objects.html["Investiga los objetos que puedan haberse perdido"]. Las alertas de objetos perdidos pueden activarse por error como medida de precaución.

En caso de que se pierdan datos de objetos sin copias, no hay ninguna solución de recuperación. Sin embargo, debes link:../troubleshoot/investigating-potentially-lost-objects.html#reset-lost-obj-count["reiniciar el contador de objetos que podrían haberse perdido"] para evitar que los objetos perdidos conocidos oculten nuevos objetos perdidos.
