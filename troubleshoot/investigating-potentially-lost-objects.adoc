= Resuelve la alerta de objetos potencialmente perdidos en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cuando se activa la alerta *Objetos potencialmente perdidos*, debes investigar de inmediato. Recopila información sobre los objetos afectados y contacta con el soporte técnico.

.Antes de empezar
* Debes haber iniciado sesión en Grid Manager usando una link:../admin/web-browser-requirements.html["navegador web compatible"].
* Tienes link:../admin/admin-group-permissions.html["permisos de acceso específicos"].
* Debes tener el archivo  `Passwords.txt`.


.Acerca de esta tarea
La alerta *Objetos potencialmente perdidos* indica que, según la información disponible en StorageGRID, no hay copias de un objeto en el grid. Es posible que los datos se hayan perdido de forma permanente.

Investiga de inmediato las alertas de objetos perdidos. Es posible que debas tomar medidas para evitar una mayor pérdida de datos. En algunos casos, es posible que puedas restaurar un objeto perdido si actúas rápidamente.


CAUTION: Si se notifican más de 10 objetos perdidos, ponte en contacto con el soporte técnico. No realices este procedimiento por tu cuenta.

.Pasos
. Selecciona *Nodos*.

... Introduce la contraseña que figura en el archivo  `Passwords.txt`. Cuando hayas iniciado sesión como root, el indicador de comandos cambia de  `$` a  `#`.
