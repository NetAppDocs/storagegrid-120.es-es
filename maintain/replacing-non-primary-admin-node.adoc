= Sustituir nodo de administración StorageGRID no primario
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para recuperar un nodo de administración que no sea el principal, primero debes sustituir el hardware físico o virtual.

Puedes sustituir un nodo de administración no primario que haya fallado por otro nodo de administración no primario que se ejecute en la misma plataforma, o puedes sustituir un nodo de administración no primario que se ejecute en VMware o en un host Linux por un nodo de administración no primario alojado en un dispositivo de servicios.

Sigue el procedimiento correspondiente a la plataforma de sustitución que elijas para el nodo. Una vez completado el procedimiento de sustitución del nodo (apto para todos los tipos de nodos), dicho procedimiento te guiará hacia el siguiente paso para la recuperación de un nodo de administración no principal.

 a| 
Linux
 a| 
link:all-node-types-replacing-linux-node.html["Sustituir un nodo de Linux"]



 a| 
Dispositivos de servicios
 a| 
link:replacing-failed-node-with-services-appliance.html["Sustituir un dispositivo de servicios"]



 a| 
OpenStack
 a| 
Los archivos de disco de máquina virtual y los scripts proporcionados por NetApp para OpenStack ya no son compatibles con las operaciones de recuperación. Si necesitas recuperar un nodo que se ejecuta en una implementación de OpenStack, descarga los archivos para tu sistema operativo Linux. Luego, sigue el procedimiento para link:all-node-types-replacing-linux-node.html["Reemplazar un nodo Linux"].
