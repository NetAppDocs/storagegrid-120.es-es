= Reúne los materiales necesarios para la recuperación de nodos de grid de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de llevar a cabo los procedimientos de mantenimiento, debes asegurarte de que dispones de los materiales necesarios para recuperar un nodo de la red que haya fallado.

[cols="1a,2a"]
|===
| Artículo | Notas 


 a| 
Archivo de instalación de StorageGRID
 a| 
Si necesitas recuperar un nodo de la red, debes <<download-and-extract-install-files-recover,Descargar los archivos de instalación de StorageGRID>> para tu plataforma.

*Nota:* No necesitas descargar archivos si estás recuperando volúmenes de almacenamiento con fallos en un Storage Node.



 a| 
${post_edited_translations.segment}
 a| 
El ordenador portátil de servicio debe tener lo siguiente:

* Puerto de red
* ${post_edited_translations.segment}
* link:../admin/web-browser-requirements.html["${post_edited_translations.segment}"]




 a| 
Archivo del paquete de recuperación `.zip`
 a| 
Consigue una copia del archivo del paquete de recuperación más reciente `.zip`:
`sgws-recovery-package-_id-revision_.zip`

El contenido del archivo  `.zip` se actualiza cada vez que se modifica el sistema. Debes guardar la versión más reciente del paquete de recuperación en un lugar seguro después de hacer esos cambios. Usa la copia más reciente para recuperarte de fallos en el grid.

Una vez que hayas iniciado sesión en cualquier nodo de administración, utiliza el Grid Manager para descargar un paquete de recuperación. Selecciona *Mantenimiento* > *Sistema* > *Paquete de recuperación*.

Si no puedes acceder al Grid Manager, puedes encontrar copias cifradas del paquete de recuperación en algunos nodos de almacenamiento que contienen el servicio ADC. En cada nodo de almacenamiento, revisa esta ubicación para el paquete de recuperación: `/var/local/install/sgws-recovery-package-_grid-id_-_revision_.zip.gpg` Usa el paquete de recuperación con el número de revisión más alto.



 a| 
`Passwords.txt` archivo
 a| 
Contiene las contraseñas necesarias para acceder a los nodos de grid desde la línea de comandos. Incluido en el paquete de recuperación.



 a| 
Contraseña de aprovisionamiento
 a| 
La frase de contraseña se crea y se documenta al instalar el sistema StorageGRID por primera vez. La frase de contraseña de aprovisionamiento no está en el archivo `Passwords.txt`.



 a| 
Documentación actual para tu plataforma
 a| 
Visita la página web del proveedor de la plataforma para consultar la documentación.

Para conocer las versiones actuales compatibles con tu plataforma, consulta https://imt.netapp.com/matrix/#welcome["Herramienta NetApp Interoperability Matrix Tool"^].

|===


[[download-and-extract-storagegrid-installation-files]]
== Descargar y descomprimir los archivos de instalación de StorageGRID

.[[descargar y extraer los archivos de instalación de recuperación]]
Descarga el software y descomprime los archivos, a menos que seas link:recovering-from-storage-node-failures.html["Recuperar volúmenes de almacenamiento con fallo en un nodo de almacenamiento"].

Debes utilizar la versión de StorageGRID que se está ejecutando actualmente en la grid.

.Pasos
. Averigua qué versión del software tienes instalada actualmente. En la parte superior de Grid Manager, selecciona el icono de ayuda y selecciona *Acerca de*.
. Ve a https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp Página de descargas de StorageGRID"^].
. Selecciona la versión de StorageGRID que se está ejecutando actualmente en el grid.
+
Las versiones del software StorageGRID tienen este formato: `11.x.y`.

. Inicia sesión con el nombre de usuario y la contraseña de tu cuenta de NetApp.
. Lee el Acuerdo de licencia de usuario final, marca la casilla de verificación y luego selecciona *Aceptar y continuar*.
. En la columna *Instalar StorageGRID* de la página de descargas, selecciona el archivo `.tgz` o `.zip` correspondiente a tu plataforma.
+
La versión que figura en el archivo de instalación debe coincidir con la versión del software que está instalada actualmente.

+
Usa el archivo  `.zip` si estás usando Windows.

+

 a|

`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz` 


 a| 
${post_edited_translations.segment}

. Descarga y descomprime el archivo comprimido.
. Ve directamente a la sección correspondiente a tu plataforma para seleccionar los archivos que necesites, en función de tu plataforma y de los nodos de grid que debas recuperar.
+
Las rutas que figuran en el paso correspondiente a cada plataforma son relativas al directorio de nivel superior instalado por el archivo comprimido.

. Si estás recuperando un link:../swnodes/index.html["nodo basado en software"], selecciona los archivos correspondientes:
