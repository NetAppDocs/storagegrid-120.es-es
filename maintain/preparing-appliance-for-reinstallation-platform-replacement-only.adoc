= Prepara el dispositivo StorageGRID para la reinstalación (solo reemplazo de plataforma)
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Al recuperar un nodo de la red que estaba alojado en un dispositivo de servicios, primero debes preparar el dispositivo para la reinstalación del software StorageGRID.

Realiza este procedimiento únicamente si vas a sustituir un nodo averiado que estaba alojado en un dispositivo de servicios. No sigas estos pasos si el nodo averiado estaba alojado originalmente en VMware o en un host Linux.

.Pasos
. Inicia sesión en el nodo de grid que ha fallado:
+
.. Introduce el siguiente comando: `ssh admin@_grid_node_IP_`
.. Introduce la contraseña que figura en el archivo  `Passwords.txt`.
.. Introduce el siguiente comando para pasar a ser usuario root: `su -`
.. Introduce la contraseña que figura en el archivo  `Passwords.txt`.


+
Cuando inicias sesión como root, el indicador cambia de  `$` a  `#`.

. Prepara el dispositivo para la instalación del software StorageGRID. Introduce: `sgareinstall`
. Cuando se te pida que continúes, introduce: `y`
+
El dispositivo se reinicia y tu sesión SSH finaliza. Normalmente, el instalador de StorageGRID Appliance tarda unos 5 minutos en estar disponible, aunque en algunos casos puede que tengas que esperar hasta 30 minutos.

+
El dispositivo de servicios se ha reiniciado y ya no se puede acceder a los datos del nodo de la red. Las direcciones IP configuradas durante el proceso de instalación original deberían permanecer intactas; sin embargo, se recomienda que lo confirmes cuando termine el procedimiento.

+
Después de ejecutar el comando  `sgareinstall`, se eliminan todas las cuentas, contraseñas y claves SSH aprovisionadas por StorageGRID, y se generan nuevas claves de host.
