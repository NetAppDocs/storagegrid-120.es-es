= Modificar la configuración de DNS para un único nodo StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
En lugar de configurar el DNS de forma global para todo el despliegue, puedes ejecutar un script para configurar el DNS de forma diferente en cada nodo de la grid.

En general, debes utilizar la opción *Mantenimiento* > *Red* > *Servidores DNS* del Grid Manager para configurar los servidores DNS. Utiliza el siguiente script únicamente si necesitas usar servidores DNS diferentes para distintos nodos de la red.

.Pasos
. El acceso externo por SSH está bloqueado de forma predeterminada. Si es necesario, link:../admin/manage-external-ssh-access.html["permitir el acceso de forma temporal"].
. Inicia sesión en el nodo de administración principal:
+
.. Introduce el siguiente comando: `ssh admin@_primary_Admin_Node_IP_`
.. Introduce la contraseña que figura en el archivo  `Passwords.txt`.
.. Introduce el siguiente comando para pasar a ser usuario root: `su -`
.. Introduce la contraseña que figura en el archivo  `Passwords.txt`.
+
Cuando inicias sesión como root, el indicador cambia de  `$` a  `#`.

.. Añade la clave privada SSH al agente SSH. Escribe: `ssh-add`
.. Introduce la contraseña de acceso SSH que figura en el archivo  `Passwords.txt`.


. [[log_in_to_node]]Inicia sesión en el nodo que quieras actualizar con una configuración DNS personalizada: `ssh _node_IP_address_`
. Ejecuta el script de configuración del DNS: `setup_resolv.rb.`
+
El script muestra la lista de comandos compatibles.

+
[listing]
----
Tool to modify external name servers

  add search <domain>
               add a specified domain to search list
               e.g.> add search netapp.com
  remove search <domain>
               remove a specified domain from list

  add nameserver <ip>
               add a specified IP address to the name server list

               remove a specified IP address from list

Enter command [`add search <domain>|remove search <domain>|add nameserver <ip>`]
              [`remove nameserver <ip>|remove nameserver all|save|abort|help`]
----
. Añade la dirección IPv4 de un servidor que proporcione el servicio de nombre de dominios para tu red: `add <nameserver IP_address>`
. Repite el comando  `add nameserver` para añadir servidores de nombres.
. Sigue las instrucciones que aparezcan para otros comandos.
. Guarda los cambios y cierra la aplicación: `save`
. [[close_cmd_shell]]Cerrar el shell de comandos del servidor: `exit`
. Para cada nodo de la red, repite los pasos desde <<log_in_to_node,iniciar sesión en el nodo>> hasta <<close_cmd_shell,cerrar la línea de comandos>>.
. Cuando ya no necesites el acceso sin contraseña a otros servidores, elimina la clave privada del agente SSH. Escribe: `ssh-add -D`
. Si has habilitado el acceso SSH externo, link:../admin/manage-external-ssh-access.html["bloquear el acceso"] cuando termines de modificar la configuración del DNS.
