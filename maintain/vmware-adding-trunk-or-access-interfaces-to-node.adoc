= Agrega interfaces trunk o de acceso a un nodo VMware en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes añadir una interfaz troncal o de acceso a un nodo de máquina virtual una vez que se haya instalado dicho nodo. Las interfaces que añadas aparecerán en la página «Interfaces de VLAN» y en la página «Grupos de alta disponibilidad».

.Antes de empezar
* Tienes acceso a las instrucciones de link:../swnodes/index.html["Instalar StorageGRID en tu plataforma VMware"].
* Tienes máquinas virtuales de VMware Admin Node y Gateway Node.
* Tienes una subred de red que no se está utilizando como Grid, Admin ni Client Network.
* Tienes el archivo  `Passwords.txt`.
* Tienes link:../admin/admin-group-permissions.html["permisos de acceso específicos"].



CAUTION: No intentes añadir interfaces a un nodo mientras una actualización de software, un procedimiento de recuperación o un procedimiento de ampliación esté activo.

.Acerca de esta tarea
Sigue estos pasos para añadir una o más interfaces adicionales a un nodo de VMware una vez instalado el nodo. Por ejemplo, puede que quieras añadir una interfaz troncal a un Admin Node o Gateway Node, así puedes usar interfaces VLAN para segregar el tráfico de diferentes aplicaciones o tenants. O quizá quieras añadir una interfaz de acceso para usarla en un grupo de alta disponibilidad (HA).

Si añades una interfaz troncal, debes configurar una interfaz de VLAN en StorageGRID. Si añades una interfaz de acceso, puedes añadir la interfaz directamente a un grupo de HA; no necesitas configurar una interfaz de VLAN.

Es posible que el nodo no esté disponible durante un breve tiempo cuando añades interfaces.

.Pasos
. En vCenter, añade un nuevo adaptador de red (tipo VMXNET3) a una VM de Admin Node y a una VM de Gateway Node. Marca las casillas *Conectado* y *Conectar al encender*.
+
image:vcenter.png["vCenter"]

. Utiliza SSH para iniciar sesión en el nodo de administración o en el nodo de puerta de enlace.
. Utiliza  `ip link show` para confirmar que se detectó la nueva interfaz de red ens256.
+
[listing]
----
ip link show
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN mode DEFAULT group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1400 qdisc mq state UP mode DEFAULT group default qlen 1000
    link/ether 00:50:56:a0:4e:5b brd ff:ff:ff:ff:ff:ff
3: eth1: <BROADCAST,MULTICAST> mtu 1500 qdisc noop state DOWN mode DEFAULT group default qlen 1000
    link/ether 00:50:56:a0:fa:ce brd ff:ff:ff:ff:ff:ff
4: eth2: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1400 qdisc mq state UP mode DEFAULT group default qlen 1000
    link/ether 00:50:56:a0:d6:87 brd ff:ff:ff:ff:ff:ff
5: ens256: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq master ens256vrf state UP mode DEFAULT group default qlen 1000
    link/ether 00:50:56:a0:ea:88 brd ff:ff:ff:ff:ff:ff
----


.Después de que termines
* Si añadiste una o más interfaces de tronco, ve a link:../admin/configure-vlan-interfaces.html["configurar interfaces VLAN"] para configurar una o más interfaces VLAN para cada nueva interfaz principal.
* Si añadiste una o más interfaces de acceso, ve a link:../admin/configure-high-availability-group.html["configurar grupos de alta disponibilidad"] para agregar las nuevas interfaces directamente a los grupos HA.
