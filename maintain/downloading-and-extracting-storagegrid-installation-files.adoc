= Descargar y descomprimir los archivos de instalación de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de poder recuperar los nodos de StorageGRID, debes descargar el software y extraer los archivos.

Debes utilizar la versión de StorageGRID que se está ejecutando actualmente en la grid.

.Pasos
. Averigua qué versión del software tienes instalada actualmente. En la parte superior de Grid Manager, selecciona el icono de ayuda y selecciona *Acerca de*.
. Ve a la página de descargas de StorageGRID de NetApp.
+
https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["Descargas de NetApp: StorageGRID"^]

. Selecciona la versión de StorageGRID que se está ejecutando actualmente en el grid.
+
Las versiones del software StorageGRID tienen este formato: 11.x.y.

. Inicia sesión con el nombre de usuario y la contraseña de tu cuenta de NetApp.
. Lee el Acuerdo de licencia de usuario final, marca la casilla de verificación y luego selecciona *Aceptar y continuar*.
. En la columna *Instalar StorageGRID* de la página de descargas, selecciona el archivo `.tgz` o `.zip` correspondiente a tu plataforma.
+
La versión que figura en el archivo de instalación debe coincidir con la versión del software que está instalada actualmente.

+
Usa el archivo  `.zip` si estás usando Windows.

+
[cols="1a,2a"]
|===
| Plataforma | Archivo de instalación 


 a| 
RHEL
| `StorageGRID-Webscale-_version_-RPM-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz` 


 a| 
Ubuntu o Debian o dispositivos preconfigurados
| `StorageGRID-Webscale-_version_-DEB-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.tgz` 


 a| 
VMware
| `StorageGRID-Webscale-_version_-VMware-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-VMware-_uniqueID_.tgz` 
|===
. Descarga y descomprime el archivo comprimido.
. Sigue el paso adecuado para tu plataforma para elegir los archivos que necesitas, según tu plataforma y los nodos de grid que necesitas recuperar.
+
Las rutas que figuran en el paso correspondiente a cada plataforma son relativas al directorio de nivel superior instalado por el archivo comprimido.

. Si estás recuperando un link:../swnodes/index.html["nodo basado en software"], selecciona los archivos correspondientes:
+
[role="tabbed-block"]
====
.RHEL
--
[cols="1a,1a"]
|===
| Ruta y nombre del archivo | Descripción 


| ./rpms/README  a| 
Un archivo de texto que describe todos los archivos que contiene el archivo de descarga de StorageGRID.



| ./rpms/NLF000000.txt  a| 
Una licencia gratuita que no da derecho a ningún tipo de asistencia técnica para el producto.



| ./rpms/StorageGRID-Webscale-Images-_version_-SHA.rpm  a| 
Paquete RPM para instalar las imágenes de los nodos de StorageGRID en tus hosts RHEL.



| ./rpms/StorageGRID-Webscale-Service-_version_-SHA.rpm  a| 
Paquete RPM para instalar el servicio de host de StorageGRID en tus hosts RHEL.



| Herramienta de creación de scripts de implementación | Descripción 


| ./rpms/configure-storagegrid.py  a| 
Un script de Python que se utiliza para automatizar la configuración de un sistema StorageGRID.



| ./rpms/configure-sga.py  a| 
Un script en Python que se utiliza para automatizar la configuración de los appliances StorageGRID.



| ./rpms/configure-storagegrid.sample.json  a| 
Un archivo de configuración de ejemplo para usar con el script  `configure-storagegrid.py`.



| ./rpms/storagegrid-ssoauth.py  a| 
Un script de Python de ejemplo que puedes usar para iniciar sesión en la Grid Management API cuando el inicio de sesión único está habilitado. También puedes usar este script para la integración con Ping Federate.



| ./rpms/configure-storagegrid.blank.json  a| 
Un archivo de configuración en blanco para usar con el script  `configure-storagegrid.py`.



| ./rpms/extras/ansible  a| 
Ejemplo de rol y playbook de Ansible para configurar hosts de RHEL para el despliegue de contenedores de StorageGRID. Puedes personalizar el rol o el playbook según sea necesario.



| ./rpms/storagegrid-ssoauth-azure.py  a| 
Un script de ejemplo en Python que puedes utilizar para iniciar sesión en la API de gestión de la red cuando el inicio de sesión único (SSO) está habilitado mediante Active Directory o Ping Federate.



| ./rpms/storagegrid-ssoauth-azure.js  a| 
Un script auxiliar llamado por el script de Python compañero `storagegrid-ssoauth-azure.py` para realizar interacciones de inicio de sesión único con Azure.



| ./rpms/extras/api-schemas  a| 
Esquemas de API para StorageGRID.

*Nota*: Antes de realizar una actualización, puedes utilizar estos esquemas para confirmar que cualquier código que hayas escrito para utilizar las API de gestión de StorageGRID será compatible con la nueva versión de StorageGRID si no tienes un entorno de StorageGRID que no sea de producción para pruebas de compatibilidad con la actualización.
