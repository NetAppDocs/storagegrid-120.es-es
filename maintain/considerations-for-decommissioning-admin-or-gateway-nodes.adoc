= Consideraciones para decomisionar un nodo Admin o Gateway de StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Revisa las consideraciones para decomisionar un nodo de administración o un nodo de gateway.



[[considerations-for-admin-node]]
== Aspectos a tener en cuenta para el nodo de administración

* No puedes decomisionar el nodo de administración principal.
* No puedes decomisionar un nodo de administración si una de sus interfaces de red forma parte de un grupo de alta disponibilidad (HA). Primero debes eliminar las interfaces de red del grupo de alta disponibilidad. Consulta las instrucciones para link:../admin/managing-high-availability-groups.html["gestión de grupos de alta disponibilidad"].
* Si es necesario, puedes modificar con total seguridad las políticas de ILM mientras decomisionas un nodo de administración.
* Si descomisionas un nodo de administración y tienes habilitado el inicio de sesión único (SSO) en tu sistema StorageGRID, debes acordarte de eliminar la confianza de parte dependiente de dicho nodo en Active Directory Federation Services (AD FS).
* Si utilizas link:../admin/grid-federation-overview.html["federación de grid"], asegúrate de que la dirección IP del nodo que vas a descomisionar no se haya especificado para una conexión de federación de grid.
* Al decomisionar un nodo de administración desconectado, perderás los registros de auditoría de ese nodo; sin embargo, estos registros también deberían existir en el nodo de administración principal.




[[considerations-for-gateway-node]]
== Consideraciones para el nodo de puerta de enlace

* No puedes decomisionar un nodo Gateway si una de sus interfaces de red forma parte de un grupo de alta disponibilidad (HA). Primero debes eliminar las interfaces de red del grupo HA. Consulta las instrucciones para link:../admin/managing-high-availability-groups.html["gestión de grupos de alta disponibilidad"].
* Si es necesario, puedes modificar con total seguridad las políticas de ILM mientras decomisionas un nodo de puerta de enlace.
* Si utilizas link:../admin/grid-federation-overview.html["federación de grid"], asegúrate de que la dirección IP del nodo que vas a descomisionar no se haya especificado para una conexión de federación de grid.
* Puedes decomisionar un Gateway Node de forma segura mientras está desconectado.
