= Selecciona Iniciar recuperación para configurar el nodo de almacenamiento del appliance StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debes seleccionar «Iniciar recuperación» en el Grid Manager para configurar un nodo de almacenamiento del appliance como sustituto del nodo que ha fallado.

.Antes de empezar
* Has iniciado sesión en Grid Manager mediante un link:../admin/web-browser-requirements.html["navegador web compatible"].
* Tienes el link:../admin/admin-group-permissions.html["Permiso de mantenimiento o acceso de usuario raíz"].
* Tienes la frase de contraseña de aprovisionamiento.
* Has implementado un nodo de almacenamiento de recovery appliance.
* Dispones de la fecha de inicio de cualquier trabajo de reparación de datos con código de borrado.


.Pasos
. Desde el Grid Manager, selecciona *Maintenance* > *Tasks* > *Recovery*.
. Selecciona el nodo de la grid que deseas recuperar en la lista Nodos pendientes.
+
Los nodos aparecen en la lista tras sufrir un fallo, pero no puedes seleccionar un nodo hasta que se haya reinstalado y esté listo para la recuperación.

. Introduce la *frase de contraseña de aprovisionamiento*.
. Haz clic en *Iniciar recuperación*.
+
image:4b_select_recovery_node.png["Captura de pantalla que muestra la página Mantenimiento > Recuperación"]

. Supervisa el progreso de la recuperación en la tabla Recuperando nodo de grid.
+
Cuando el nodo de la grid llegue a la fase «Esperando pasos manuales», pasa al siguiente tema y realiza los pasos manuales para volver a montar y formatear los volúmenes de almacenamiento del appliance.

+
image:recovery_reset_button.gif["Captura de pantalla que muestra la etapa esperando los pasos manuales"]

+

NOTE: En cualquier momento durante la recuperación, puedes hacer clic en *Restablecer* para iniciar una nueva recuperación. Aparecerá un cuadro de diálogo en el que se indica que el nodo quedará en un estado indeterminado si restableces el procedimiento.

+
image:recovery_reset_warning.gif["Captura de pantalla que muestra el cuadro de diálogo de advertencia de restablecimiento de recuperación"]

+
Si deseas volver a intentar la recuperación tras reiniciar el procedimiento, debes restaurar el nodo del dispositivo a su estado de preinstalación ejecutando  `sgareinstall` en dicho nodo.
