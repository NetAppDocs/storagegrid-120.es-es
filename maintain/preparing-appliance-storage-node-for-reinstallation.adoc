= Prepara el nodo de almacenamiento del dispositivo StorageGRID para la reinstalación
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Al recuperar un nodo de almacenamiento (Storage Node), primero debes preparar el dispositivo para la reinstalación del software StorageGRID.

.Pasos
. Inicia sesión en el nodo de almacenamiento que ha fallado:
+
.. Introduce el siguiente comando: `ssh admin@_grid_node_IP_`
.. Introduce la contraseña que figura en el archivo  `Passwords.txt`.
.. Introduce el siguiente comando para pasar a ser usuario root: `su -`
.. Introduce la contraseña que figura en el archivo  `Passwords.txt`.


+
Cuando inicias sesión como root, el indicador cambia de  `$` a  `#`.

. Prepara el nodo de almacenamiento del dispositivo para la instalación del software StorageGRID. `sgareinstall`
. Cuando se te pida que continúes, introduce: `y`
+
El dispositivo se reinicia y tu sesión SSH finaliza. Normalmente, el instalador de StorageGRID Appliance tarda unos 5 minutos en estar disponible, aunque en algunos casos puede que tengas que esperar hasta 30 minutos.

+

CAUTION: No intentes acelerar el reinicio apagando y volviendo a encender el dispositivo ni reiniciándolo de ninguna otra forma. Podrías interrumpir actualizaciones automáticas de la BIOS, el BMC u otro firmware.

+
El nodo de almacenamiento del dispositivo StorageGRID se ha reiniciado y ya no se puede acceder a los datos que contiene. Las direcciones IP configuradas durante el proceso de instalación original deberían permanecer intactas; no obstante, se recomienda que lo compruebes una vez finalizado el procedimiento.

+
Después de ejecutar el comando  `sgareinstall`, se eliminan todas las cuentas, contraseñas y claves SSH aprovisionadas por StorageGRID, y se generan nuevas claves de host.
