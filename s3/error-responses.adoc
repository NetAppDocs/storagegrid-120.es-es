[[storagegrid-custom-error-codes]]
== Códigos de error personalizados de StorageGRID

[cols="2a,2a,1a"]
|===
| Nombre | Descripción | Estado HTTP 


 a| 
XBucketLifecycleNotAllowed
 a| 
No se permite la configuración del ciclo de vida de un bucket Compliant heredado
 a| 
400 Solicitud incorrecta



 a| 
XBucketPolicyParseException
 a| 
No se pudo analizar el JSON de la política del bucket recibido.
 a| 
400 Solicitud incorrecta



 a| 
XComplianceConflict
 a| 
Operación denegada debido a la configuración heredada de Compliance.
 a| 
403 Prohibido



 a| 
XComplianceReducedRedundancyForbidden
 a| 
No se permite la redundancia reducida en el bucket Compliant heredado.
 a| 
400 Solicitud incorrecta



 a| 
XMaxBucketPolicyLengthExceeded
 a| 
Tu política supera la longitud máxima permitida para una bucket policy.
 a| 
400 Solicitud incorrecta



 a| 
XMissingInternalRequestHeader
 a| 
Falta un encabezado en una solicitud interna.
 a| 
400 Solicitud incorrecta



 a| 
XNoSuchBucketCompliance
 a| 
El bucket especificado no tiene habilitado el Compliance heredado.
 a| 
404 No encontrado



 a| 
XNoAceptable
 a| 
La solicitud contiene uno o varios encabezados «Accept» que no se pudieron satisfacer.
 a| 
406 No aceptable



 a| 
XNoImplementado
 a| 
La solicitud que has enviado implica una funcionalidad que no está implementada.
 a| 
501 No implementado

|===
