= Operaciones compatibles de Amazon S3 Select en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID admite las siguientes cláusulas de Amazon S3 Select, tipos de datos y operadores para el link:select-object-content.html["SelectObjectContent comando"].


NOTE: Los artículos que no figuren en la lista no son compatibles.

Para consultar la sintaxis, visita link:select-object-content.html["SelectObjectContent"]. Para obtener más información sobre S3 Select, consulta https://docs.aws.amazon.com/AmazonS3/latest/userguide/selecting-content-from-objects.html["Documentación de AWS sobre S3 Select"^].

Solo las cuentas de inquilino que tengan habilitada la función S3 Select pueden realizar consultas SelectObjectContent. Consulta link:../admin/manage-s3-select-for-tenant-accounts.html["Consideraciones y requisitos para usar S3 Select"].
