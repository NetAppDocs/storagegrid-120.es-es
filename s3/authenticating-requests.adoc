= Cómo StorageGRID S3 REST API autentica las solicitudes
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El sistema StorageGRID admite tanto el acceso autenticado como el acceso anónimo a los objetos mediante la API de S3.

La API de S3 admite Signature version 2 y Signature version 4 para autenticar las solicitudes de la API de S3.

Las solicitudes autenticadas deben firmarse utilizando tu ID de clave de acceso y tu clave de acceso secreta.

El sistema StorageGRID admite dos métodos de autenticación: el encabezado HTTP `Authorization` y el uso de parámetros de consulta.



[[use-the-http-authorization-header]]
== Utiliza el encabezado de autorización HTTP

El encabezado HTTP `Authorization` se utiliza en todas las operaciones de la API de S3 excepto en las solicitudes anónimas donde lo permite la política del bucket. El encabezado `Authorization` contiene toda la información de firma necesaria para autenticar una solicitud.



[[use-query-parameters]]
== Usa parámetros de consulta

Puedes utilizar parámetros de consulta para añadir información de autenticación a una URL. Esto se conoce como la prefirma de la URL, que puede usarse para conceder acceso temporal a recursos específicos. Los usuarios que tengan la URL prefirmada no necesitan conocer la clave de acceso secreta para acceder al recurso, lo que te permite proporcionar acceso restringido a terceros a un recurso.
