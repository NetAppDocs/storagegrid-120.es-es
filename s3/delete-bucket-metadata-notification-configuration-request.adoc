= Desactiva el servicio de integración de búsqueda con la solicitud de configuración de notificación de metadatos DELETE Bucket en StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La solicitud de configuración de notificaciones de metadatos de DELETE Bucket te permite desactivar el servicio de integración de búsqueda para buckets concretos eliminando el archivo XML de configuración.

Debes tener el permiso s3:DeleteBucketMetadataNotification para un bucket, o ser account root, para completar esta operación.



[[request-example]]
== Ejemplo de solicitud

Este ejemplo muestra cómo desactivar el servicio de integración de búsqueda para un bucket.

[listing, subs="specialcharacters,quotes"]
----
DELETE /test1?x-ntap-sg-metadata-notification HTTP/1.1
Date: _date_
Authorization: _authorization string_
Host: _host_
----
